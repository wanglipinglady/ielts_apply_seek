## 1. Python 脚本问题

### 1.1 argparse 参数定义错误

**问题描述**：
```python
# 错误写法
parser.add_argument('--all', '-a', help='...')  # 需要一个值

# 运行时报错
usage: convert_course.py [-h] [--output-dir OUTPUT_DIR] [--all ALL] docx_file
convert_course.py: error: argument --all/-a: expected one argument
```

**解决方案**：
使用 `action='store_true'` 使其为布尔标志：
```python
parser.add_argument('--all', '-a', action='store_true', help='...')

# 同时让 docx_file 参数变为可选
parser.add_argument('docx_file', nargs='?', help='Word 文档路径')
```

### 1.2 docx 表格解析错误

**问题描述**：
```python
# 错误代码
for element in self.doc.element.body:
    if element.tag.endswith('tbl'):
        table_data = self._parse_table(element)  # element 是 CT_Tbl 对象
        for row in table.rows:  # ❌ 报错：'CT_Tbl' object has no attribute 'rows'
```

**解决方案**：
直接使用 `doc.tables` 列表：
```python
def _parse(self):
    # 先收集所有段落
    for para in self.doc.paragraphs:
        self._process_paragraph(para)
    
    # 再处理所有表格
    for table in self.doc.tables:
        table_data = self._parse_table(table)
        self._process_table(table_data)

def _parse_table(self, table):
    data = []
    for row in table.rows:  # ✅ 正确：table 是 Table 对象
        row_data = [cell.text.strip() for cell in row.cells]
        data.append(row_data)
    return data
```

### 1.3 段落索引计算错误

**问题描述**：
```python
# 错误代码
para = self.doc.paragraphs[len([...]) if element in self.doc.element.body]
# 报错：应为 "else"、"[ " 未关闭
```

**解决方案**：
简化逻辑，直接遍历 paragraphs：
```python
def _parse(self):
    for para in self.doc.paragraphs:
        self._process_paragraph(para)
```

## 3. 编码问题

### 3.1 Windows PowerShell 中文乱码

**问题描述**：
```
# 太空探索
来源: 鍓戞ˉ闆呮€?
```

**原因**：Windows PowerShell 默认使用 GBK/ANSI 编码，不支持 UTF-8 中文。

**解决方案**：

#### 方法 1：PowerShell 配置文件（推荐）
创建/编辑 `~/Documents/WindowsPowerShell/Microsoft.PowerShell_profile.ps1`：
```powershell
# UTF-8 encoding for Python CLI
$env:PYTHONIOENCODING = "utf-8"
chcp 65001 > $null
```

#### 方法 2：每次运行前设置
```powershell
$env:PYTHONIOENCODING = "utf-8"
chcp 65001 > $null
ib course show 太空探索
```

#### 方法 3：macOS/Linux
默认 UTF-8，无需配置。

### 3.2 click.echo_via_pager 编码问题

**问题描述**：
使用 `click.echo_via_pager()` 在 Windows 下可能输出乱码。

**解决方案**：

import sys
md = svc.get_markdown(topic)

## 4. 文件路径问题

### 4.1 CourseService 路径计算错误

**问题描述**：
课程列表显示"暂无课程"，但 `courses/` 目录确实存在。

**原因**：
```python
# 错误：从 config.py 的 app_dir 向上找，路径不对
from ielts_buddy.core.config import get_app_dir
self._courses_dir = get_app_dir().parent / "courses"
```

**解决方案**：
使用 `__file__` 向上查找：
```python
def __init__(self, courses_dir: Path | None = None) -> None:
    if courses_dir is None:
        # 从 src/ielts_buddy/services/course_service.py 向上三级到项目根目录
        self._courses_dir = Path(__file__).resolve().parents[3] / "courses"
    else:
        self._courses_dir = courses_dir
```

**路径层级说明**：
```
项目根目录/
├── courses/                    ← 目标目录 (parents[3])
├── src/
│   └── ielts_buddy/
│       └── services/
│           └── course_service.py  ← 当前文件 (parents[0])
```

| parents[n] | 路径 |
|------------|------|
| parents[0] | services/ |
| parents[1] | ielts_buddy/ |
| parents[2] | src/ |
| parents[3] | 项目根目录/ |

## 5. 解析逻辑问题

### 5.1 docx 转换后内容为空

**问题描述**：
运行 `python scripts/convert_course.py --all` 后，生成的 `content.json` 为空：
```json
{
  "topic": "...",
  "core_sentence": {},
  "vocabulary": [],
  ...
}
```

**原因**：
CardParser 的 `_parse_core_sentence()` 和 `_process_table()` 正则匹配过于严格，无法匹配实际的 Word 文档格式。

**解决方案**：

#### 方案 1：手动创建完整的 content.json（快速解决）
直接编写正确格式的 JSON 文件，确保包含：
- `core_sentence.en` / `core_sentence.cn`
- `vocabulary[]` 数组
- `grammar.structure` / `grammar.diagram`
- `writing_template{}` 对象

#### 方案 2：改进解析器（长期方案）
- 放宽正则匹配条件
- 支持多种表格格式
- 增加调试输出，查看实际解析结果

### 5.2 正则表达式匹配模式

**常用正则**：

| 目的 | 表达式 | 示例 |
|------|--------|------|
| 提取主题 | `Sentence?\d+_(.+?)_知识卡片` | `Sentence01_太空探索_知识卡片.docx` → `太空探索` |
| 提取音标 | `/([^/]+)/` | `/kənˈsɪdərəbl/` → `kənˈsɪdərəbl` |
| 提取单词 | `([a-zA-Z\-]+)` | `considerable /kən...` → `considerable` |

## 6. 常见错误速查

| 错误信息 | 原因 | 解决方案 |
|----------|------|----------|
| `expected one argument` | argparse 参数缺少 `action='store_true'` | 添加 `action='store_true'` |
| `'CT_Tbl' has no attribute 'rows'` | 直接遍历 XML 元素 | 使用 `doc.tables` |
| `No such command 'course'` | 命令未注册 | `cli.add_command(course)` |
| 中文乱码 | Windows 编码问题 | 设置 `$env:PYTHONIOENCODING="utf-8"` + `chcp 65001` |
| 路径不存在 | `parents[n]` 计算错误 | 检查层级，使用 `Path(__file__).resolve()` |
