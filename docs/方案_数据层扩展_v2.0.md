## 1. 目标与边界

### 1.1 目标

1. 保留 SQLite 作为单机模式的唯一存储，向后兼容现有所有用户数据
2. 新增 MySQL 联网模式，云端已有 MySQL，支持远程连接
3. CLI 启动可自由切换两种模式，不强制升级
4. 联网模式下通过 `username` 区分不同用户数据
5. 为后续 web 页面 + 多用户登录预留接口

### 1.2 非目标（明确不做）

- **不做混合模式**：不维护本地缓存与云端的同步
- **不做数据迁移工具**：单机模式的用户数据**不**自动同步到联网模式
- **不做冲突解决**：联网模式不关心本地 SQLite 数据，反之亦然
- **不做密码 / Token / JWT**：联网模式仅靠 `username` 区分用户（无认证），后续 web 阶段再补
- **不做多端实时同步**：单机模式用户在多台电脑上的数据互相独立
- **不做数据导入导出自动调度**：导出仍走现有 `ib sync all`

### 1.3 设计原则

- **不破坏现有 CLI 体验**：命令、参数、输出格式不变
- **Repository 抽象先行**：未来 web 阶段复用同一套接口
- **配置驱动**：所有可选项进 `config.toml`，不在代码里硬编码
- **`user_id` 一次到位**：所有业务表都带 `user_id` 列，本机模式固定为 `1`

### 3.2 模式定义

#### 模式 A：单机模式（`mode = "local"`）

- 行为与现状 100% 一致
- 走 `SQLiteRepository`，数据库 `~/.ib/data.db`
- `user_id` 固定为 `1`（不感知）
- 适合：单设备、纯本地、不需要多用户隔离

#### 模式 B：联网模式（`mode = "remote"`）

- 走 `MySQLRepository`，连接云端 MySQL
- CLI 启动后要求输入 `username`，所有读写带 `user_id`
- MySQL 表结构与 SQLite 保持一致（详见 §4）
- 适合：多设备共享进度（每台电脑各自启动联网模式 + 同一 username）、多用户隔离

### 3.5 Repository 抽象层

#### 3.5.1 接口定义（`src/ielts_buddy/core/repository.py`）

```python
from typing import Protocol, Optional
from datetime import date
from ielts_buddy.core.models import (
    LearningRecord, PersonalWord, VocabCategory,
    ExamSession, ExamReport, GradeResult, Word,
)

class LearningRepository(Protocol):
    """学习记录 + 艾宾浩斯复习（核心闭环）"""

    def get_record(self, user_id: int, word: str) -> Optional[LearningRecord]: ...
    def upsert_record(self, user_id: int, word: Word, correct: bool,
                      source: str = "builtin") -> LearningRecord: ...
    def get_due_words(self, user_id: int, limit: int = 20) -> list[dict]: ...
    def get_due_count(self, user_id: int) -> int: ...
    def get_all_records(self, user_id: int) -> list[LearningRecord]: ...
    def toggle_star(self, user_id: int, word: str) -> bool: ...
    def get_history(self, user_id: int, days: int) -> list[dict]: ...


class PersonalVocabRepository(Protocol):
    """个人词库 + 分类管理"""

    def add_word(self, user_id: int, pw: PersonalWord) -> int: ...
    def edit_word(self, user_id: int, name: str, **kwargs) -> None: ...
    def delete_word(self, user_id: int, name: str) -> None: ...
    def get_word(self, user_id: int, name: str) -> Optional[PersonalWord]: ...
    def list_words(self, user_id: int, category: Optional[str],
                   page: int, per_page: int) -> list[PersonalWord]: ...
    def get_word_count(self, user_id: int) -> int: ...
    def add_to_category(self, user_id: int, word: str, category: str) -> None: ...
    def list_categories(self, user_id: int) -> list[VocabCategory]: ...
    # ... 其他方法


class ExamRepository(Protocol):
    def create_exam(self, user_id: int, band: int, count: int,
                    time_limit: int) -> ExamSession: ...
    def submit_answer(self, user_id: int, session_id: str,
                      q_index: int, answer: str) -> dict: ...
    def finish_exam(self, user_id: int, session_id: str) -> ExamReport: ...
    def get_history(self, user_id: int, limit: int) -> list[dict]: ...


class GradeRepository(Protocol):
    def save_result(self, user_id: int, result: GradeResult) -> int: ...
    def get_history(self, user_id: int, limit: int,
                    task_type: Optional[str]) -> list[GradeResult]: ...
    def get_average_score(self, user_id: int) -> float: ...
    def get_error_trend(self, user_id: int, limit: int) -> list[dict]: ...


class UserRepository(Protocol):
    """用户表（仅联网模式使用，单机模式为空实现）"""

    def get_or_create(self, username: str) -> int: ...
    def get_by_id(self, user_id: int) -> Optional[dict]: ...
```

#### 3.5.2 关键设计点

- **每个方法都带 `user_id` 参数**：单机模式下统一传 `1`，强制所有 Repository 感知用户隔离
- **返回值是 Pydantic 模型，不是 `sqlite3.Row`**：彻底解耦存储细节
- **方法命名跨方言一致**：`upsert_record` 对 SQLite 是 `INSERT ... ON CONFLICT`，对 MySQL 是 `INSERT ... ON DUPLICATE KEY UPDATE`

#### 3.5.3 接口演进预留

未来 web + 多用户登录（方案 C）时，**接口层不动**，仅替换实现：

```python
# 现在（方案 B）
class MySQLRepository:
    def get_record(self, user_id: int, word: str):
        # 直接连 MySQL
        with self._engine.connect() as conn:
            ...

# 未来（方案 C）
class HTTPRepository:
    def get_record(self, user_id: int, word: str):
        # 通过 HTTP 调 FastAPI
        r = httpx.get(f"{self.base_url}/learning/records/{word}",
                      headers={"Authorization": f"Bearer {self.token}"})
        return LearningRecord(**r.json())
```

Services 层、Commands 层、CLI 入口**一行不动**。

### 3.6 工厂 + 配置加载（`src/ielts_buddy/core/db_factory.py`）

```python
def create_repositories(config: Config) -> dict:
    mode = config.get("database.mode", "local")
    if mode == "local":
        return _create_sqlite_repositories()
    elif mode == "remote":
        username = config.get("database.current_user")
        if not username:
            raise ValueError("联网模式需要先设置 database.current_user")
        return _create_mysql_repositories(config, username)
    else:
        raise ValueError(f"未知 mode: {mode}")
```

### 3.7 模式切换命令

新增 `ib mode` 命令组：

```bash
ib mode show              # 查看当前模式 + 当前用户 + 连接信息
ib mode switch            # 交互式切换模式（带确认）
ib mode switch local      # 直接切到单机
ib mode switch remote     # 直接切到联网（提示输入 username）
ib user                   # 显示当前 username

```

`ib user list` 在联网模式下执行 `SELECT username FROM users ORDER BY created_at DESC`；单机模式提示"该命令仅联网模式可用"。

### 3.8 单机 → 联网的过渡

**不做数据迁移**。给用户清晰提示：

```
? 检测到你当前是单机模式，已有 1,250 条学习记录。

  联网模式不会自动迁移这些数据，是否继续？
  ❯ 是的，继续切换
    取消
    导出当前数据为 JSON（保留在本机）
```

如果选"导出"，调用现有 `ib sync all` 把数据存到 `~/.ib/sync/`，用户可手动导入（未来 web 端做导入功能）。

### 3.9 联网 → 单机的过渡

同理，**不迁移**。提示用户：

```
? 联网模式下用户 'rory_x' 有 1,250 条学习记录。

  切换到单机模式后，这些数据不会自动下载到本机。
  后续可随时切回联网模式查看。
  ❯ 继续切换
    取消
```

## 4. 数据库 Schema 设计

### 4.1 共用约束

- **所有业务表必须带 `user_id` 字段**（单机模式固定为 1）
- **主键策略**：SQLite 用 `INTEGER PRIMARY KEY AUTOINCREMENT`；MySQL 用 `BIGINT PRIMARY KEY AUTO_INCREMENT`
- **字符集**：MySQL 用 `utf8mb4`
- **时间字段**：存 ISO 字符串（与现状一致，避免时区问题）

### 4.2 users 表（仅 MySQL 模式）

```sql
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(64) UNIQUE NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    last_login_at DATETIME
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

> 联网模式启动时输入 `username`，先 `SELECT` 查存在性，不存在则 `INSERT`，再把 `user_id` 缓存到进程内存。

### 4.3 业务表加 `user_id`

```sql
-- learning_records
ALTER TABLE learning_records ADD COLUMN user_id BIGINT NOT NULL DEFAULT 1;
CREATE INDEX idx_user_word ON learning_records(user_id, word);

-- personal_vocab
ALTER TABLE personal_vocab ADD COLUMN user_id BIGINT NOT NULL DEFAULT 1;
CREATE INDEX idx_pv_user ON personal_vocab(user_id);

-- vocab_categories
ALTER TABLE vocab_categories ADD COLUMN user_id BIGINT NOT NULL DEFAULT 1;

-- exam_sessions
ALTER TABLE exam_sessions ADD COLUMN user_id BIGINT NOT NULL DEFAULT 1;

-- grade_history
ALTER TABLE grade_history ADD COLUMN user_id BIGINT NOT NULL DEFAULT 1;
```

**SQLite 与 MySQL 共用同一份 DDL**（用 SQLAlchemy Core 描述方言差异）。

### 4.4 索引设计

| 表 | 索引 |
|---|---|
| `learning_records` | `(user_id, word)` UNIQUE / `(user_id, next_review)` |
| `personal_vocab` | `(user_id, word)` UNIQUE / `(user_id, category_id)` |
| `exam_sessions` | `(user_id, started_at DESC)` |
| `grade_history` | `(user_id, graded_at DESC)` |

### 12.5 系统分类种子模板实现（3-A 决策落地）

**思路**：用 `user_id=0` 作为"模板用户"，其下的 `favorites` / `mistakes` 两行作为种子；新用户首次进入联网模式时，业务层用 `INSERT ... SELECT` 把种子复制到该用户。

**步骤 1**：MySQL 初始化脚本（§12.2 已有）已写入种子行：

```sql
INSERT IGNORE INTO vocab_categories (user_id, name, description, is_system) VALUES
    (0, 'favorites',  '收藏夹',  1),
    (0, 'mistakes',   '错词本',  1);
```

> 注：`UNIQUE KEY uk_vc_user_name (user_id, name)` 允许多个用户拥有同名分类，user_id=0 这一份仅作为模板存在。

**步骤 2**：在 `repositories/mysql_repo.py` 的 `UserRepository.ensure_system_categories(user_id)` 方法中实现复制逻辑：

```python
def ensure_system_categories(self, user_id: int) -> None:
    """用户首次进入联网模式时，从 user_id=0 模板复制系统分类到该用户。

    设计：user_id=0 的两行 (favorites, mistakes) 是种子；
    每个新用户首登时执行一次，后续 (user_id, name) UNIQUE 保证不会重复。
    """
    with self._engine.connect() as conn:
        # 1) 检查用户是否已有系统分类（防御性，正常首次应该没有）
        result = conn.execute(
            text("""
                SELECT COUNT(*) AS cnt FROM vocab_categories
                WHERE user_id = :uid AND is_system = 1
            """),
            {"uid": user_id},
        ).fetchone()
        if result.cnt > 0:
            return  # 已存在，跳过

        # 2) 从 user_id=0 模板复制
        conn.execute(
            text("""
                INSERT INTO vocab_categories (user_id, name, description, is_system, word_count, created_at)
                SELECT :uid, name, description, is_system, 0, NOW()
                FROM vocab_categories
                WHERE user_id = 0 AND is_system = 1
            """),
            {"uid": user_id},
        )
        conn.commit()
```

**步骤 3**：调用时机——`UserRepository.get_or_create(username)` 返回 user_id 之后立即调用：

```python
def get_or_create(self, username: str) -> int:
    with self._engine.connect() as conn:
        row = conn.execute(
            text("SELECT id FROM users WHERE username = :u"), {"u": username}
        ).fetchone()
        if row:
            user_id = row.id
        else:
            result = conn.execute(
                text("INSERT INTO users (username) VALUES (:u)"),
                {"u": username},
            )
            conn.commit()
            user_id = result.lastrowid

        # 关键：首次登录时复制系统分类
        self.ensure_system_categories(user_id)

        # 顺便更新 last_login_at
        conn.execute(
            text("UPDATE users SET last_login_at = NOW() WHERE id = :uid"),
            {"uid": user_id},
        )
        conn.commit()
        return user_id
```

```python
def test_ensure_system_categories_idempotent(mysql_repo):
    """重复调用 ensure_system_categories 不应产生重复分类。"""
    user_id = mysql_repo.get_or_create("bob")
    mysql_repo.ensure_system_categories(user_id)
    mysql_repo.ensure_system_categories(user_id)
    cats = mysql_repo.list_categories(user_id)
    assert len([c for c in cats if c.is_system]) == 2
```

### 12.6 CI 自动 diff 校验（4-B 决策落地）

**目标**：任何人改了 `pyproject.toml` 忘记同步 `requirements.txt`，CI 直接报错。

**新增脚本** `scripts/check_deps_sync.py`：

```python
#!/usr/bin/env python3
"""检查 pyproject.toml 与 requirements.txt 的依赖是否一致。

CI 在 pytest 之前跑这个脚本，不一致就 fail。
"""
import re
import sys
from pathlib import Path

try:
    import tomllib
except ModuleNotFoundError:
    import tomli as tomllib  # type: ignore


def parse_pyproject(path: Path) -> set[str]:
    """从 pyproject.toml 提取 dependencies 段的所有包名（去掉版本约束）。"""
    data = tomllib.loads(path.read_text(encoding="utf-8"))
    deps = data.get("project", {}).get("dependencies", [])
    return {_pkg_name(d) for d in deps}


def parse_requirements(path: Path) -> set[str]:
    """从 requirements.txt 提取所有包名（忽略 -e、-r、注释、空行）。"""
    result = set()
    for line in path.read_text(encoding="utf-8").splitlines():
        line = line.strip()
        if not line or line.startswith("#") or line.startswith("-"):
            continue
        result.add(_pkg_name(line))
    return result


def _pkg_name(spec: str) -> str:
    """从 'click>=8.0' / 'pydantic>=2.0,<3' 中提取包名。"""
    return re.split(r"[<>=!~;\[]", spec, 1)[0].strip().lower()


def main() -> int:
    root = Path(__file__).resolve().parents[1]
    toml_deps = parse_pyproject(root / "pyproject.toml")
    txt_deps = parse_requirements(root / "requirements.txt")

    missing_in_txt = toml_deps - txt_deps
    extra_in_txt = txt_deps - toml_deps

    if not missing_in_txt and not extra_in_txt:
        print(f"OK: 两个文件依赖一致 ({len(toml_deps)} packages)")
        return 0

    print("FAIL: pyproject.toml 与 requirements.txt 依赖不一致", file=sys.stderr)
    if missing_in_txt:
        print(f"  - pyproject.toml 有但 requirements.txt 缺: {sorted(missing_in_txt)}",
              file=sys.stderr)
    if extra_in_txt:
        print(f"  - requirements.txt 有但 pyproject.toml 缺: {sorted(extra_in_txt)}",
              file=sys.stderr)
    print("  请同步两文件后重试。可参考：", file=sys.stderr)
    print("    pip freeze | grep -E '(click|rich|pydantic|jinja2|openai|anthropic|sqlalchemy|pymysql|cryptography)' > requirements.txt",
          file=sys.stderr)
    return 1


if __name__ == "__main__":
    sys.exit(main())
```

```yaml

    steps:
    - uses: actions/checkout@v4
    - uses: actions/setup-python@v5

        python-version: '3.11'
    - run: pip install -e ".[dev]"
    # v2.2 新增：依赖一致性校验

```
