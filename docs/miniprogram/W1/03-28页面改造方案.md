## 三、28 页面逐页决策表

### 3.1 鉴权类（4 页）

| Web 路由 | 用途 | 决策 | 理由 |
|----------|------|------|------|
| `/login` | 登录 | **简化** | 复用微信登录（`wx.login` + 后端换 JWT），不再单独做用户名/密码；保留"手机号 + 验证码"备选 |
| `/register` | 注册 | **简化** | 微信登录 + 自动注册；不开放用户手动注册，避免账号垃圾 |
| `/change-password` | 修改密码 | **砍掉** | 微信登录态天然不需要密码；如保留仅做"解绑手机号" |
| `/forgot-password` | 忘记密码 | **砍掉** | 同上，微信登录态自行重置 |

### 3.2 仪表盘与统计（3 页）

## 六、与 AI 开发模式 SKILL 的页面映射

| SKILL 名称 | 调起场景 | 触发页面 | 优先级 |
|------------|----------|----------|--------|
| `vocab_buddy`（词汇搭子） | 用户说「来 5 个 Band 7 词」 | 任意页聊天框 → Tab 1 | P0 |
| `review_buddy`（复习搭子） | 用户说「我今天该复习什么」 | Tab 2 → 复习入口 | P0 |
| `speak_buddy`（口语搭子） | 用户说「来一道 Part 2 旅行话题」 | Tab 3 → 口语入口 | P0（W3） |
| `grade_buddy`（写作搭子） | 用户说「帮我批改这篇作文」 | Tab 4 → 写作入口 | P1（W3） |
| `cloze_buddy`（填空搭子） | 用户说「给我 5 个 Band 8 完形填空」 | Tab 3 → Reading 入口 | P2（W6） |

> SKILL 总量上限 30 个；本项目规划占用 5 个，安全裕度充足。
