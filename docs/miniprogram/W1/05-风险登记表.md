## 八、应急响应 SOP

### 8.1 类目申请被拒（R-Q-01）
- D+1：立即提交备选类目「工具-效率」
- D+2：写申诉邮件（举证「教育-辅助工具」业内通行做法）
- D+3：仍被拒 → 启动"借企业资质"备选方案

### 8.2 AI 开发模式权限未到（R-Q-02 / R-E-01 / R-E-09）
- W4 D-3（9/18）：复查提审通道是否开放（官方"AI 开发模式"页或公告栏）
- W4 D+1：若开放 → 立即提交 SKILL 代码审核 + 上线
- W4 D+3：仍无消息 → 改走"自建 LLM API + 微信云开发 AI 能力"路径
- W4 D+5：Demo 中保留 SKILL 文档 + 申请截图作为评审材料
- W5 deadline：必须先发布一个不带 SKILL 的精简版上线（满足"比赛期间必须正式上线"硬要求），SKILL 通道开放后再发升级版

### 8.3 LLM / Whisper 服务挂掉（R-E-02 / R-E-03）
- 客户端：loading 状态 + retry 2 次 + 退避
- 服务端：多 Key 轮询 + 排队 + 熔断
- 兜底：写死"评分暂时不可用"提示，开放"查看历史评分"

### 8.4 真机白屏（R-A-03）
- W2 每日真机冒烟（iOS + Android 各 1 次）
- 主包拆包：词库 → 异步分 Band 加载
- 关键页面 fallback：极端情况降级到 text-only 模式
