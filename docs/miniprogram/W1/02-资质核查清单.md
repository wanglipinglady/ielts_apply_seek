## 一、结论先行（评审 & 团队内部共识用）

| 问题 | 结论 |
|------|------|
| 个人开发者能否做「雅思备考」小程序？ | **能**，但必须以「学习工具」形态而非「在线培训」形态提交 |
| 是否需要办学许可证？ | **不需要**（只要不挂「在线视频课程」「成人技能培训」「课程销售」类目） |
| 是否需要 ICP 备案 / 视听许可？ | **不需要**（自用云函数 / 自建 API 走 HTTPS 不触发；不向第三方提供视听节目） |
| 是否需要接入微信 AI 开发模式？ | **强烈建议**——是评审「创新性」维度证据，但目前为内测，需提前申请 |
| 是否需要接入 ClawBot？ | **可选**，但能显著强化「微信生态独家」故事线 |
| 微信支付 / 虚拟支付能开吗？ | **不能**（个人主体禁止），变现走流量主 |

## 二、个人主体 vs 企业主体对照表

| 维度 | 个人主体 | 企业主体 |
|------|----------|----------|
| 适用类目 | 工具 / 查询 / 学习辅助（个人类目表） | 全类目开放（含教育-培训、教育-在线视频课程） |
| 能否挂「教育-在线视频课程」 | **不能** | 可以，但需办学许可 / 视听许可 / ICP |
| 能否挂「教育-成人技能培训」 | **不能** | 可以，需办学许可证或人社备案 |
| 能否挂「课程销售」 | **不能** | 可以，需增值电信业务经营许可证 |
| 能否挂「教育-辅助工具」 | **能**（业内通行做法） | 能 |
| 微信支付 | **不能用** | 能用 |
| 流量主开通门槛 | 累计 UV ≥ 1000 + 无违规 | 累计 UV ≥ 1000 + 无违规 |
| 资质办理时间 | 即时 | 增值电信业务经营许可证：30–60 工作日 |
| 适合本项目吗？ | **是**（MVP 首选） | 后期如需上线课程销售再升级 |

> **推荐路径**：W1–W5 用个人主体跑通 MVP，W6 视情况升级企业主体（如要接入 ClawBot 商业化能力）。

## 三、可挂靠的服务类目（按「适配度 × 资质难度」排序）

| 类目 | 适配度 | 个人可挂 | 资质要求 | 是否推荐 |
|------|--------|----------|----------|----------|
| 教育-辅助工具（背单词 / 题库练习） | ★★★★★ | 是 | 无 | **首选** |
| 工具-效率（查询 / 提醒） | ★★★★ | 是 | 无 | 备选 |
| 工具-图片音视频处理（用于口语音频） | ★★★ | 是 | 无 | 备选 |
| 教育-在线视频课程 | ★★★★★ | **否** | 办学许可 / 视听许可 | 不走 |
| 教育-成人技能培训 | ★★★★ | **否** | 办学许可证 | 不走 |
| 教育-课程销售平台 | ★★★ | **否** | 增值电信业务经营许可证 | 不走 |
| 教育-出国留学 | ★★★ | **否** | 营业执照含教育咨询 | 不走 |

> 「教育-辅助工具」虽然业内通行做法（CSDN / 技术站多篇文章均提及），但官方「非个人主体开放类目」表未单独列示；提交时如被拒可改投「工具-效率」类目，并在提报材料的「功能说明」中明确学习辅助定位。

## 四、必须办理 / 可绕开的资质清单

### 4.1 必须办理（个人 MVP 也躲不开的）

| 资质 | 用途 | 难度 | 时间成本 |
|------|------|------|----------|
| 微信小程序个人主体账号（邮箱 + 身份证） | 注册 AppID 必备 | 低 | 当天 |
| 一个未绑定过微信公众平台的邮箱 | 注册主体账号 | 低 | 即时 |
| 服务器域名 + SSL 证书（自有 / 微信云开发免） | 后端 API HTTPS | 低 | 当天（云开发） / 1–3 天（自有） |
| 微信支付商户号 | 暂不开通（个人主体禁用） | — | — |
| AI 开发模式内测申请 | SKILL 调度的官方入口 | 中 | 1–7 天 |

### 4.2 可绕开（前提：纯工具 + 不收费 + 不挂课程）

| 资质 | 触发条件 | 绕开方式 |
|------|----------|----------|
| 民办学校办学许可证 | 类目挂「在线视频课程」「成人技能培训」 | 类目改为「教育-辅助工具」 |
| 信息网络传播视听节目许可证 | 自建视听节目分发 | 不做直播、不做付费课；用户录音仅本地评分，不上传第三方平台 |
| ICP 备案 | 域名直接对公众提供服务 | 使用微信云开发 / Serverless，平台已代备案 |
| 双减相关资质 | 学科类校外培训（K12 语文/数学/英语课标内容） | 本项目仅面向**雅思**（出国留学考试），非 K12 学科类，不在双减范围 |
| 增值电信业务经营许可证 | 在线课程交易、虚拟商品交易 | 不做付费课 / 虚拟商品 |
| 教育 APP 备案 | 教育类移动应用 | 小程序在「移动应用」备案体系中已合并，提交小程序即视为完成 |

## 五、AI 内容合规（与 AI 开发模式挂钩）

| 红线 | 我们怎么做 |
|------|------------|
| 不得生成违反公德 / 违法 / 妨害未成年人身心健康的内容 | 提示词内置安全护栏；不收集未成年人身份信息 |
| 对话记录需加密存储 ≥ 30 天 | 后端加密落库（沿用 Web 端 `auth/security.py` 的 hash 方案） |
| 隐私协议需在使用 AI 功能前明示并同意 | 小程序首次进入弹窗 + 设置页常驻 |
| 生成内容需标识 AI 痕迹 | 写作批改页底部加「本评语由 AI 生成，仅供参考」一行小字 |
| 不得诱导未成年人付费 | 个人主体本就无支付能力，自然规避 |

> 依据：微信《平台常见拒绝情形》3.2.8.10 + 2026-01-23 网信办《可能影响未成年人身心健康的网络信息分类办法》 + 2026-07-13 微信珊瑚安全微短剧违规处置公告对 AI 生成内容的统一审核标准。

## 六、ClawBot / iLink 接入的额外合规点（如启用）

| 项 | 要求 | 备注 |
|----|------|------|
| 接入方式 | 通过 `npx cc-weixin` 等桥接器扫码登录个人微信 | 个人使用推荐方案 ① |
| 内容边界 | 文本 / 图片 / 视频 / 文件双向 | 不支持位置 / 红包 / 转账 / 朋友圈 |
| 风控风险 | 高频 / 批量自动回复会被风控识别 | 控制单日推送频次（建议 ≤ 30 条/账号） |
| 协议合规 | iLink 协议属微信内部协议，官方明确禁止第三方使用 | 桥接器为灰色地带，谨慎使用 |

## 七、上线审核常见拒绝情形（提前规避）

| 拒绝原因 | 提前规避动作 |
|----------|--------------|
| 类目与功能不符 | 选「教育-辅助工具」并在小程序简介明确「雅思学习工具，非培训课程」 |
| 涉及在线培训收费 | 没有任何支付入口、课程购买入口 |
| 涉及 K12 学科类内容 | 所有学习内容限定「雅思 / 出国留学」语境 |
| 未提供隐私协议 | 设置页常驻「隐私协议」「用户协议」入口 |
| 未做 AI 内容标识 | 任何 AI 生成内容底部加「由 AI 生成」标识 |
| 收集用户敏感信息 | 不收集身份证、银行卡、人脸；仅微信登录 + 学习数据 |
