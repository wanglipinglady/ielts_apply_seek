## 二、服务内容

本小程序为你提供以下**雅思备考学习辅助**服务：

| 服务名称 | 服务描述 |
|----------|----------|
| **词汇学习** | 提供雅思核心词库（Band 5–9）的浏览、抽词、测验功能 |
| **艾宾浩斯复习** | 基于艾宾浩斯遗忘曲线自动调度复习计划 |
| **口语录音评分** | 用户录音 → 服务端转写（Whisper）→ LLM 按雅思口语四维评分 |
| **写作批改** | 用户粘贴文本 → LLM 按雅思写作四维评分 + 改写建议 |
| **错词本** | 自动汇总所有答错的单词，按错次排序 |
| **学习数据统计** | 每日学习量、正确率、Band 进度可视化 |
| **AI 智能推荐** | 基于学习记录推荐薄弱环节、新学内容 |

本小程序**仅提供学习辅助工具**，不提供：
- ❌ 在线视频课程
- ❌ 直播授课
- ❌ 课程销售
- ❌ 付费内容
- ❌ 任何形式的学历 / 职业资格培训
