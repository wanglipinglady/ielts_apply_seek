## 一、备案前的5 个前置判断

| 决策 | 取值 | 备注 |
|------|------|------|
| 主体类型 | 个人 | 已确认（不是企业） |
| 服务器 | 阿里云 ECS（你已租赁） | 必须先买阿里云域名才能走阿里云备案通道 |
| 域名后缀 | `.cn`（推荐）/ `.com` | `.cn` 备案审核更快、政策友好 |
| 域名用途 | 仅作 API 服务域名 | 不做网站、不做博客、不做电商 |
| 接入方式 | 自建 API（**不是云开发**） | 决定备案"网站类型"字段填什么 |

> **本清单只覆盖"自建 API"路径**。如果你后面改主意用微信云开发，**无需备案**。

## 二、需要准备的全部材料（一次性备齐）

### 2.1 必备材料

| # | 材料 | 形式 | 来源 | 备注 |
|---|------|------|------|------|
| 1 | **身份证正反面** | 清晰拍照/扫描（JPG/PNG） | 个人 | 4 个角完整、无反光、信息可读 |
| 2 | **《网站备案真实性核验单》** | PDF（系统自动生成） | 阿里云备案系统 | 提交后系统会推送下载链接 |
| 3 | **域名证书** | 阿里云自动同步 | 阿里云域名控制台 | 买完域名后系统自动出现 |
| 4 | **备案人手机号** | 用于接收验证码 | 个人 | 不能与已备案账号的手机号重复 |
| 5 | **备案人邮箱** | 用于接收进度通知 | 个人 | 建议用 Gmail / Outlook（不与阿里云账号邮箱冲突） |
| 6 | **阿里云 ECS 服务器** | 已租赁 | 已具备 | 备案时需选择"关联的服务器实例" |

### 2.2 视情况需要的材料

| 情况 | 额外材料 |
|------|----------|
| **非户籍地备案**（如户籍河北但人在北京） | 居住证 / 暂住证 / 当地社保连续 6 个月证明 |
| **域名持有人在公司名下**（已买但非你名下）| 公司营业执照 + 授权书（**你这种情况不需要**）|
| **个人名下已有 5 个备案网站** | 个人主体上限5 个，超了要先注销 1 个 |

> **绝大多数个人开发者只需要 2.1 的 6 项**。**今晚先确认自己是不是非户籍地备案**——这决定要不要额外材料。

## 三、阿里云备案全流程（10 步走完）

### 步骤 1：买域名（5 分钟，今晚必做）

| 子步骤 | 操作 |
|--------|------|
| 1.1 | 登录 [阿里云控制台](https://ecs.console.aliyun.com) → 域名注册 |
| 1.2 | 搜索候选域名（建议：`ielts-buddy.cn`、`ielts-buddy.com.cn`、`api.yasidatazi.cn`）|
| 1.3 | 选择未被注册的域名 → 加入购物车 → 结算（首年几十块，`.cn` 首年 29 元）|
| 1.4 | 完成实名认证（身份证信息）—— **这是备案的前置条件** |
| 1.5 | 域名 WHOIS 信息可设为你的真实姓名 |

**域名选择建议**：

| 候选 | 优点 | 缺点 |
|------|------|------|
| `ielts-buddy.cn` | 品牌名直出、`.cn` 政策友好 | 已被注册概率高 |
| `api.yasidatazi.cn` | API 子域、专业感强 | 名字长一点 |
| `ielts-buddy.com.cn` | 折中方案 | 审核稍慢 |

> **建议**：`ielts-buddy.cn` 没被注册就用这个；否则选 `api.yasidatazi.cn` 备用。

### 步骤 2：登录阿里云备案系统（2 分钟）

| 子步骤 | 操作 |
|--------|------|
| 2.1 | 访问 [beian.aliyun.com](https://beian.aliyun.com) |
| 2.2 | 用阿里云账号登录（**如果还没账号，用手机号注册**）|
| 2.3 | 进入「备案管理」控制台 |

### 步骤 3：填写主办者信息（10 分钟）

| 字段 | 怎么填 | 备注 |
|------|--------|------|
| 主办者名称 | 你的**真实姓名**（与身份证一致）| 个人备案 |
| 主办者证件类型 | 身份证 | — |
| 主办者证件号码 | 身份证号 | — |
| 主办者通讯地址 | **当前实际居住地址**（精确到门牌号）| 与身份证或居住证一致 |
| 主办者手机号 | 备案本人的手机 | 不能是阿里云账号已绑定的手机 |
| 主办者邮箱 | Gmail / Outlook（避免用阿里云邮箱 / QQ 邮箱的常见别名）| 用于接收审核结果 |

### 步骤 4：填写网站信息（15 分钟，重点字段）

| 字段 | 怎么填 | 关键 |
|------|--------|------|
| 网站名称 | `雅思搭子 API 服务` | 4–30 字符，**不能带"中国""国家""中华"等敏感词** |
| 网站服务内容 | **选「其他」** 或 「互联网信息服务」 | **不要**选"电子商务 / 论坛 / 博客"等 |
| 网站语言 | 中文（简体） | — |
| 域名 | 你刚买的域名（如 `api.yasidatazi.cn`） | 不带 `http://`，不带路径 |
| 网站备案号 | 首次备案：留空 | — |
| 前置审批项 | **无** | 不涉及新闻 / 教育 / 医疗 / 出版等前置审批 |
| 网站负责人 | 同主办者 | 个人备案同一人 |
| IP 地址 | **填你阿里云 ECS 的公网 IP** | 在 ECS 控制台「实例」页面查看 |

### 步骤 5：填写接入信息（5 分钟）

| 字段 | 怎么填 |
|------|--------|
| 接入服务提供商 | 阿里云 |
| 接入方式 | **自建**（**不是云开发 / 不是虚拟主机**） |
| 服务器类型 | ECS 云服务器 |
| 服务器地域 | 你 ECS 所在的地域（如 华东 1 / 华北 2）|
| 关联实例 | 选择你租赁的那台 ECS |

### 步骤 6：上传核验材料（5 分钟）

- 上传身份证正反面照片
- 系统生成《核验单》PDF，**下载后打印 → 手写签字 → 拍照上传**（部分地区已支持电子签）
- 部分地区（广东 / 上海 / 北京）需要"幕布拍照"——阿里云会邮寄一块幕布给你，**挂着幕布拍照上传**

### 步骤 7：阿里云初审（1–3 个工作日）

- 阿里云客服人工审核你的资料
- 通过 → 进入下一步
- 不通过 → 短信通知你"哪项有问题"，修改后重新提交

### 步骤 8：工信部短信核验（关键，1–2 个工作日）

- 阿里云初审通过后，**工信部会发短信**到你备案手机号
- 短信里有个**核验链接 + 验证码**
- **你必须在 24 小时内点击链接 + 输入验证码完成核验**
- ⚠️ **不操作 = 备案自动失败**——很多人卡在这一步

### 步骤 9：管局审核（5–20 个工作日）

- 工信部把申请转到你所在省 / 市的通信管理局
- 管局人工审核
- 通过 → 工信部官网可查到你
- 不通过 → 短信通知原因

### 步骤 10：备案成功（拿到备案号）

- 工信部下发**备案号**（格式：`京ICP备12345678号-1`）
- **你必须在 30 天内**在网站底部加上备案号（虽然你的 API 域名不展示网页，但部分管局会扫）
- 阿里云备案后台 →「我的备案」可下载备案号

## 四、备案期间你能做什么（不要干等）

| 可以做 | 说明 |
|--------|------|
| W2 前端开发 | 用 `127.0.0.1` 跑后端 + 微信开发者工具「不校验合法域名」 |
| 后端 wx-login 接口开发 | 与备案无关，**先写先测** |
| 准备 SSL 证书申请材料 | 备案下来当天就能申请 |
| 准备 Nginx 配置 | 提前写好，备案下来 30 分钟内上线 |
| 写隐私协议 + 用户协议 | 8/30 截止前必交 |

| 不能做 | 说明 |
|--------|------|
| ❌ 小程序添加 request 合法域名 | 必须等备案下来 |
| ❌ 真实环境真机联调 | 公网域名无法访问，ICP 备案审核期间域名会被锁定 |
| ❌ 提交审核版本 | 必须等备案下来 |

## 五、备案下来后的 30 分钟动作

备案成功当天，按顺序做这 5 件事：

| 步骤 | 动作 | 时间 |
|------|------|------|
| 1 | 阿里云控制台 → SSL 证书 → 申请免费 DV SSL（绑你的域名）| 5 分钟 |
| 2 | SSL 证书签发后下载 Nginx 包 | 1 分钟 |
| 3 | 公众平台 → 开发管理 → 开发设置 → 服务器域名 → 添加 `https://api.你的域名.cn` | 1 分钟 |
| 4 | ECS 上装 Nginx（`yum install nginx` 或 `apt install nginx`）| 10 分钟 |
| 5 | Nginx 配置 SSL + 反代 8000 → uvicorn | 10 分钟 |

**备案下来 + 这 5 步做完 = 小程序可上线**

## 六、常见驳回原因 + 提前规避

| 驳回原因 | 概率 | 提前规避 |
|----------|------|----------|
| **身份证不清晰** | 中 | 用手机原生相机拍，避免用扫描 App（压缩过度）|
| **居住地与户籍不符 + 无居住证** | 高（外地人）| 提前办居住证，或先回户籍地备案 |
| **网站名称含敏感词**（"国家""中国""中华"）| 低 | 网站名称填"雅思搭子 API 服务"，**不带这些词** |
| **网站服务内容填错**（如选"论坛"）| 中 | 选「其他」或「互联网信息服务」 |
| **接入方式填错**（如选"云开发"）| 低 | 选"自建" |
| **幕布拍照不规范** | 中 | 等阿里云寄幕布 + 自然光 + 正面无遮挡 |
| **工信部短信核验超时** | 中 | 收到短信立刻操作，**不要拖到晚上** |
| **联系方式无效** | 低 | 手机号保持开机，邮箱定期查看 |

