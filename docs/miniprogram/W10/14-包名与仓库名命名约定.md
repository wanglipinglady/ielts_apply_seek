# 包名 vs 仓库名 命名约定（2026-09-29）

> **结论**：不重命名。仓库名 `ielts_apply_seek`，Python 包名 `ielts_buddy` 是 Python 项目惯例。

---

## 1. 三种名字的关系

| 名字类型 | 值 | 用在哪 |
|---|---|---|
| **GitHub 仓库名** | `ielts_apply_seek` | git remote、目录名、URL |
| **Python 包名（PyPI）** | `ielts-buddy` | `pip install ielts-buddy`、pyproject.toml 的 `name` |
| **Python 模块路径** | `ielts_buddy` | `from ielts_buddy.web.main import app` |
| **部署目录** | `/opt/ielts_apply_seek/` | ECS 实际部署位置 |

**速查表**：

| 场景 | 用哪个名字 |
|---|---|
| `git clone` URL | `ielts_apply_seek`（仓库名） |
| `pip install` | `ielts-buddy`（PyPI 名） |
| `import` 语句 | `ielts_buddy`（模块名） |
| uvicorn 启动 | `ielts_buddy.web.main:app`（模块路径） |
| ECS 部署目录 | `/opt/ielts_apply_seek/`（仓库名） |

---

## 2. 为什么仓库名 ≠ 包名

### 2.1 GitHub 仓库名偏好连字符

- URL 友好：`https://github.com/user/ielts-apply-seek`（SEO 友好）
- 行业标准：`python-dateutil`、`scikit-learn`、`django-rest-framework`
- 复制方便：连字符比下划线在 URL 里更清晰

### 2.2 Python 模块路径不能有连字符

```python
# ✅ 下划线（合法）
from ielts_buddy.web.main import app

# ❌ 连字符（非法，Python 解析器报错）
from ielts-apply-seek.web.main import app
# SyntaxError: invalid syntax
```

### 2.3 PyPI 包名可以用连字符，但只是"显示名"

```toml
[project]
name = "ielts-buddy"   # PyPI 上的包名，可以有连字符
```

实际安装到 site-packages 后，目录名是**下划线版本**（自动转换）：

```
site-packages/ielts_buddy/    # 自动转下划线
site-packages/ielts_buddy-0.1.0.dist-info/
```

## 3. 业界惯例对照表

| 仓库名（连字符）| Python 包名 | import 名 | 部署目录 |
|---|---|---|---|
| `django-rest-framework` | `djangorestframework` | `rest_framework` | `/opt/django-rest-framework/` |
| `python-dateutil` | `python-dateutil` | `dateutil` | `/opt/python-dateutil/` |
| `scikit-learn` | `scikit-learn` | `sklearn` | `/opt/scikit-learn/` |
| `tensorflow-models` | `tensorflow-models` | `official` 或 `tf_models` | `/opt/tensorflow-models/` |
| `pyyaml` | `pyyaml` | `yaml` | `/opt/pyyaml/` |
| `requests` | `requests` | `requests` | `/opt/requests/`（恰好同名） |
| `ielts_apply_seek` | `ielts-buddy` | `ielts_buddy` | `/opt/ielts_apply_seek/` |

**结论**：**仓库名 ≠ import 名是 Python 社区常态**，不是 bug。

## 4. 改包名的工程量（量化）

| 类型 | 数量 | 改的位置 |
|---|---|---|
| `from ielts_buddy.xxx import ...` | ~150 处 | 所有 .py 文件 |
| 文件路径 `src/ielts_buddy/` | 50+ 目录和文件 | mv + import 同步 |
| `pyproject.toml` | 2 处 | `name` + `packages` |
| entry_points（CLI 命令） | 2-3 处 | pyproject.toml |
| 测试代码 `tests/` 引用 | 几十处 | grep -rl |
| systemd unit | 1 处 | `/etc/systemd/system/ielts-web.service` |
| 数据库文件名 | 多个 | `get_web_db_path()` 等 |
| **总计** | **500+ 处** | — |

**风险**：

- 🟠 中高（每个改动都要回归测试）
- 🟡 时间成本：半天到一天
- 🟡 部署期间可能中断服务
- 🟢 收益：**0**（改完还会有新的不一致）

## 5. 如果一定要改（强烈不推荐）

### 5.1 推荐用自动化工具

```bash
# 安装 rope（Python 重构工具）
pip install rope

# 在 src/ 目录执行批量重命名
cd /opt/ielts_apply_seek
rope rename . ielts_buddy ielts_apply_seek

# 验证
python -c "from ielts_apply_seek.web.main import app; print('OK')"
```

### 5.2 改完后必须更新的位置

| 文件 | 改什么 |
|---|---|
| `pyproject.toml` | `name = "ielts-apply-seek"` + `packages = ["src/ielts_apply_seek"]` |
| `src/ielts_buddy/` → `src/ielts_apply_seek/` | `mv` 整个目录 |
| 所有 `from ielts_buddy.xxx import` | 改为 `from ielts_apply_seek.xxx import` |
| systemd unit 的 `ExecStart` | `uvicorn ielts_apply_seek.web.main:app` |
| `tests/` | 所有 import |
| 数据库文件名（可选） | `~/.ielts-buddy/ielts_buddy.db` → `~/.ielts-apply-seek/ielts_apply_seek.db` |

### 5.3 注意事项

**Python 包名不能有连字符**：

```python
# ❌ 错误（连字符）
import ielts-apply-seek  # SyntaxError

# ✅ 正确（下划线）
import ielts_apply_seek
```

所以即使你改了仓库名，Python 包名也必须是下划线版本——**这又制造了新的不一致**（仓库名 `ielts-apply-seek` vs 包名 `ielts_apply_seek`）。
