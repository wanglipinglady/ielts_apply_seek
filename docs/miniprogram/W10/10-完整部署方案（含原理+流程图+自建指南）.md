# 个人服务器多域名完整部署方案（v3.9 / 2026-09-28）

> **适用对象**：想在 1 台阿里云 ECS 上部署多个项目（个人网站 + 雅思备考助手）。
> **核心思路**：用 Nginx 反向代理 + 子域名隔离，每个项目独立部署、独立证书。
> **本文目的**：让你能脱离 AI 工具自己也能维护。

---

## 1. 架构总览

### 1.1 网络请求流向

```
用户浏览器/微信小程序
   │
   │ HTTPS (TCP 443)
   ↓
DNS 解析（阿里云 DNS）
   wanglipingresume.com      → 118.190.148.121
   ielts.wanglipingresume.com → 118.190.148.121
   www.wanglipingresume.com    → 118.190.148.121
   │
   ↓
阿里云 ECS（118.190.148.121）
   │
   ├─ Nginx :443（监听所有 HTTPS 请求）
   │     │
   │     │ 根据 server_name 路由
   │     ↓
   │     ├─ server_name wanglipingresume.com → 静态文件 /var/www/personal/
   │     └─ server_name ielts.wanglipingresume.com → proxy_pass 127.0.0.1:8000
   │
   ├─ uvicorn :8000（雅思备考助手 FastAPI）
   │     └─ 连云端 MySQL 118.190.148.121:3306
   │
   └─ MySQL :3306（云端数据库）
```

### 1.2 端口分配

| 端口 | 服务 | 暴露方式 |
|---|---|---|
| 22 | SSH | 公网（仅你的 IP） |
| 80 | Nginx HTTP（跳转 HTTPS） | 公网 |
| 443 | Nginx HTTPS | 公网 |
| 3306 | MySQL | **只允许 ECS 内网** |
| 8000 | uvicorn | **只监听 127.0.0.1**（不暴露公网） |

**关键原则**：
- 任何业务端口（uvicorn、MySQL）**只监听 localhost**
- 只有 Nginx 监听 80/443 公网
- 通过 Nginx 反向代理到内网端口

## 2. 技术原理（基础知识）

### 2.1 什么是反向代理（Reverse Proxy）

```
[正向代理]：客户端 → 代理服务器 → 目标服务器
   例子：公司内网通过代理服务器访问外网
   
[反向代理]：客户端 → 反向代理服务器 → 后端服务器
   例子：用户访问 wanglipingresume.com → Nginx（代理）→ 你的网站
```

**反向代理的作用**：

1. **隐藏真实端口**：用户只看到 443，不知道后面有 uvicorn 8000
2. **TLS 终止**：Nginx 处理 HTTPS，后端走 HTTP（性能更好）
3. **负载均衡**：可转发到多个后端实例
4. **静态资源**：Nginx 直接服务静态文件，比 uvicorn 快
5. **路由分发**：一个 IP + 443 端口，根据域名分发到不同应用

### 2.2 域名 → IP 的解析（DNS）

```
浏览器访问 wanglipingresume.com
   ↓
   1. 查询操作系统 DNS 缓存
   2. 查询 /etc/resolv.conf 里的 DNS 服务器
   3. 阿里云 DNS（你的域名注册商）
   4. 返回 IP：118.190.148.121
   ↓
浏览器连接 118.190.148.121:443
```

**为什么要备案**：国内 DNS 服务器要求 `.cn` 或国内访问的境外域名必须备案，否则返回"该网站暂时无法访问"。

### 2.3 HTTPS / SSL / TLS

```
HTTP（明文）：不安全，任何人都能窃听
HTTPS = HTTP + TLS（加密）
TLS 握手过程：
   1. 客户端发 ClientHello（支持的加密算法）
   2. 服务器回 ServerHello + 证书（公钥）
   3. 客户端验证证书（CA 机构签名）
   4. 双方协商出对称密钥
   5. 用对称密钥加密后续通信

为什么需要 SSL 证书？
   - 防止中间人攻击（MITM）
   - 浏览器只信任 CA 机构签名的证书
   - 自签证书会被浏览器警告
```

### 2.4 systemd 是什么

```
systemd = Linux 系统的"服务管家"
   - 开机自启服务
   - 崩溃自动重启
   - 统一日志管理
   - 资源限制（CPU/内存）
   - 依赖管理（先启动 MySQL，再启动 uvicorn）

配置文件：/etc/systemd/system/<service-name>.service
查看状态：systemctl status <service-name>
查看日志：journalctl -u <service-name> -f
```

### 2.5 完整的请求时序图

```
T0    用户在微信里点击"开始答题"
T0+1  小程序（wx.request）→ HTTPS GET https://ielts.wanglipingresume.com/api/wx/study/review/due
T0+2  DNS 查询 ielts.wanglipingresume.com → 118.190.148.121
T0+3  TCP 连接到 118.190.148.121:443
T0+4  TLS 握手（验证证书、建立加密通道）
T0+5  Nginx 接收请求：Host=ielts.wanglipingresume.com
T0+6  Nginx 匹配 server_name，找到 ielts.wanglipingresume.com 的 server 配置块
T0+7  Nginx 反向代理 → http://127.0.0.1:8000/api/wx/study/review/due
T0+8  uvicorn 接收请求，匹配路由 wx_speak_start
T0+9  uvicorn 调 service 层 → 查 MySQL 118.190.148.121:3306
T0+10 MySQL 返回查询结果
T0+11 uvicorn 包装 JSON 返回
T0+12 Nginx 把响应加密后返回给小程序
T0+13 小程序收到响应，更新界面

总耗时：~100ms
```

#### 0.4 安全组（关键！）

阿里云 ECS 控制台 → 网络与安全 → 安全组 → 配置规则：

| 端口 | 协议 | 源 | 用途 |
|---|---|---|---|
| 22 | TCP | 你的 IP / 0.0.0.0/0 | SSH |
| 80 | TCP | 0.0.0.0/0 | HTTP（跳转） |
| 443 | TCP | 0.0.0.0/0 | HTTPS |
| 3306 | TCP | **仅 ECS 内网**（172.16.0.0/12） | MySQL |

> ⚠️ 3306 绝不能 0.0.0.0/0 暴露公网！

### Step 4：Nginx 配置

#### 4.1 个人网站配置

```bash
sudo vim /etc/nginx/sites-available/personal
```

```nginx
# HTTP 跳转 HTTPS
server {
    listen 80;
    server_name wanglipingresume.com www.wanglipingresume.com;
    return 301 https://wanglipingresume.com$request_uri;
}

# HTTPS 主网站
server {
    listen 443 ssl http2;
    server_name wanglipingresume.com www.wanglipingresume.com;

    ssl_certificate     /etc/nginx/ssl/wanglipingresume.com/wanglipingresume.com.pem;
    ssl_certificate_key /etc/nginx/ssl/wanglipingresume.com/wanglipingresume.com.key;
    ssl_protocols       TLSv1.2 TLSv1.3;

    add_header Strict-Transport-Security "max-age=31536000" always;

    root /var/www/wanglipingresume;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/personal /etc/nginx/sites-enabled/
sudo mkdir -p /var/www/wanglipingresume
echo "<h1>wanglipingresume.com</h1>" > /var/www/wanglipingresume/index.html
```

#### 4.2 雅思备考助手配置

```bash
sudo vim /etc/nginx/sites-available/ielts
```

```nginx
server {
    listen 80;
    server_name ielts.wanglipingresume.com;
    return 301 https://ielts.wanglipingresume.com$request_uri;
}

server {
    listen 443 ssl http2;
    server_name ielts.wanglipingresume.com;

    ssl_certificate     /etc/nginx/ssl/ielts.wanglipingresume.com/ielts.wanglipingresume.com.pem;
    ssl_certificate_key /etc/nginx/ssl/ielts.wanglipingresume.com/ielts.wanglipingresume.com.key;
    ssl_protocols       TLSv1.2 TLSv1.3;

    add_header Strict-Transport-Security "max-age=31536000" always;
    client_max_body_size 30M;

    access_log /var/log/nginx/ielts-access.log;
    error_log  /var/log/nginx/ielts-error.log;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_read_timeout 60s;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/ielts /etc/nginx/sites-enabled/
```

```ini
Type=simple
User=deploy
Group=deploy

ExecStart=/opt/ielts_buddy/.venv/bin/uvicorn ielts_buddy.web.main:app --host 127.0.0.1 --port 8000 --workers 2

StandardError=append:/var/log/ielts-buddy/web-error.log

[Install]
WantedBy=multi-user.target
```

## 6. 安全检查清单

部署完后逐项检查：

- [ ] SSH 禁用密码登录（只用密钥）
- [ ] MySQL 只监听 127.0.0.1（不暴露公网）
- [ ] uvicorn 只监听 127.0.0.1
- [ ] Nginx 隐藏版本号：`server_tokens off;`
- [ ] SSL 证书链完整（SSL Labs 测 A 评级）
- [ ] HSTS 启用
- [ ] `.env` 文件权限 600
- [ ] 定期更新系统：`sudo apt update && sudo apt upgrade`
- [ ] fail2ban 安装（防 SSH 爆破）

## 7. 故障排查速查

| 症状 | 排查 |
|---|---|
| 502 Bad Gateway | `sudo systemctl status ielts-web` 看 uvicorn 状态 |
| 证书错误 | `sudo nginx -t` + `curl -vI https://...` 看 TLS 握手 |
| MySQL 连不上 | `mysql -h 127.0.0.1 -u ielts_app -p` 测登录 |
| DNS 不生效 | `dig wanglipingresume.com` 看是否解析到 ECS IP |
| 小程序"不在合法域名" | 公众平台检查域名 + 协议 + 端口（不能带端口） |
