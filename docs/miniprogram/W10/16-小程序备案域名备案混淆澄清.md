# 小程序备案 vs 域名备案 vs 小程序认证（2026-09-29）

> **重要澄清**：很多开发者（包括我自己）会把「域名备案」「小程序备案」「小程序认证」混淆。这三个**完全不同**。

---

## 1. 三个概念的对比

| 概念 | 主管部门 | 适用对象 | 必要性 | 时间 |
|---|---|---|---|---|
| **ICP 备案**（域名备案）| 工信部 | 域名（如 `wanglippingresume.com`）| 在国内用**该域名**访问服务**必须备案** | 7-20 天 |
| **小程序备案**（2024 新规）| 各地通信管理局 | **微信小程序本身** | 2024-12-25 起所有新小程序**必须备案** | 7-20 天 |
| **小程序认证**（个人/企业）| 微信官方 | 微信小程序 | 个人**不用**；企业类（涉及支付/特定类目）**才需要** | 1-3 天 |

---

## 2. ICP 备案（域名备案）

### 是什么

- 任何要在国内提供**公网服务**的域名都必须 ICP 备案
- 工信部强制要求（《中华人民共和国电信条例》）
- 不备案 → 国内 DNS 解析被屏蔽 → 用户无法访问

### 你的情况

- ✅ `wanglippingresume.com` 已备案（截图显示"已备案"）
- ✅ `ielts.wanglippingresume.com` 是子域名，**自动继承**主域名的备案
- 这就是为什么 `https://ielts.wanglipingresume.com/` 能从公网访问

### 不需要做的事

- ❌ 不需要单独申请 `ielts.wanglipingresume.com` 的备案（**子域名**自动共享）
- ❌ 不需要把 SSL 证书也备案
- ❌ 不需要给小程序备案相关的域名

---

## 3. 小程序备案（2024 新规）

### 是什么

- 2024-12-25 起，工信部要求**所有新注册的微信小程序**做"小程序备案"
- 不备案 → **无法发布上线**给真实用户（开发版/体验版不受影响）

### 与域名备案的关系

- **完全独立**！域名 ICP 备案 ≠ 小程序备案
- 域名备案是**服务器层面**的合规
- 小程序备案是**应用层面**的合规

### 你要做的

#### 路径 A：通过微信公众平台提交

```
https://mp.weixin.qq.com
   ↓
登录（管理员扫码）
   ↓
设置 → 基本设置 → 微信小程序备案
   ↓
填写材料：
   - 主办单位性质（个人 / 企业 / 政府 / 媒体）
   - 主办单位证件（身份证 / 营业执照）
   - 主体负责人
   - 小程序负责人
   - 小程序备案信息表
   ↓
提交审核（7-20 个工作日）
   ↓
通过 / 拒绝（不通过会说明原因）
```

#### 路径 B：通过服务器所在地通信管理局

```
各省通信管理局官网 → ICP 备案 → 小程序备案
   （但通常微信公众平台已经集成了这个流程，从入口提交即可）
```

### 需要的材料（个人 / 企业）

| 个人 | 企业 |
|---|---|
| 身份证正反面 | 营业执照 |
| 手机号 | 法人身份证 |
| 邮箱 | 对公账户（少数类目需要）|
| 紧急联系人 | 备案负责人身份证 |
| 小程序负责人承诺书（微信平台下载模板）| |

### 时间

- 个人备案：约 7-15 天
- 企业备案：约 15-20 天（更严的审核）

---

## 4. 小程序认证（个人/企业）

### 是什么

- 微信官方的"商户号认证"
- 300 元 / 年
- **不是**必须的，**仅影响"高级接口"**

### 影响

| 能力 | 个人 | 已认证企业 |
|---|---|---|
| 微信支付 | ❌ 需要 | ✅ 可用 |
| 获取手机号 | ✅ 可用（用户主动授权） | ✅ 可用 |
| 获取 unionid | ✅ 可用 | ✅ 可用 |
| 客服消息 | 限制次数 | 无限次 |
| 小程序类目限制 | 部分类目 | 更多 |

### 你的项目（雅思备考助手）

- ❌ **不需要**认证（不需要微信支付）
- ✅ 个人小程序足够

---

## 5. 你现在问的关键问题答案

> "发布给真实用户需要小程序备案通过吗？"

**简短答**：

- **2024-12-25 之前注册的微信小程序**：**不需要**备案，发布不受影响
- **2024-12-25 之后注册的新小程序**：**必须**备案后才能发布

### 你的情况（看小程序注册时间）

1. 打开 [微信公众平台](https://mp.weixin.qq.com) → 设置 → 基本设置
2. 看"微信小程序"账号的**注册时间**
3. 如果是 2024-12-25 之后 → 必须备案
4. 如果是 2024-12-25 之前 → 直接发布

### 你的截图能看出注册时间吗？

之前的 `wanglippingresume.com` 备案截图里显示"到期时间 2027年9月16日"——这是**域名 ICP 备案**，不是小程序备案。

要看小程序备案状态：

```
微信公众平台 → 设置 → 基本设置 → 微信小程序备案
或
微信公众平台 → 设置 → 基本设置 → 账号信息 → 主体信息
```

## 6. 备案 vs 发布的完整流程

### 不需要小程序备案的情况

```
开发版：IDE 直接预览
   ↓
体验版：扫码给朋友测试
   ↓
⚠️ 未备案前只能到这里 ⚠️
```

### 需要小程序备案的情况

```
体验版 OK
   ↓
微信开发者工具 → 上传代码
   ↓
微信公众平台 → 版本管理 → 提交审核
   ↓
微信审核团队（1-3 天）
   ↓
审核通过 → 备份发布 / 全量发布
   ↓
普通用户可搜索/扫码访问你的小程序
```

## 7. 域名备案 vs 小程序备案的常见混淆

| 我以为是 | 实际是 |
|---|---|
| "域名备案了，小程序不用再备案" | ❌ 这是**两个独立**的备案 |
| "小程序备案了，域名不用再备案" | ❌ 同样独立 |
| "小程序发布必须域名备案" | ✅ 对（小程序要 HTTPS 调接口，接口域名必须备案）|
| "域名备案了，小程序一定能发布" | ❌ 还需小程序备案 |
| "小程序认证 = 小程序备案" | ❌ 完全不同的两件事 |
| "小程序认证是必须" | ❌ 个人 / 普通功能不需要 |

## 8. 你（个人开发者）的完整备案清单

### 必须做

| 项目 | 状态 | 行动 |
|---|---|---|
| **域名 ICP 备案**（wanglippingresume.com）| ✅ 已完成 | 无 |
| **小程序备案**（2024-12-25 后新规）| ❓ 看你注册时间 | 查公众平台 → 可能需要备案 |

### 可选做

| 项目 | 是否需要 | 行动 |
|---|---|---|
| **小程序认证**（300 元/年）| ❌ 不需要 | 个人开发无需 |
| **SSL 证书** | ✅ 已签发 | 无（自动覆盖子域名）|

### 不需要做

| 项目 | 原因 |
|---|---|
| 单独申请 `ielts.wanglipingresume.com` 备案 | 子域名自动共享主域名 |
| 给后端服务器备案 | 服务器不需要备案，域名才需要 |
| 给 SSL 证书备案 | 证书本身不需要 |

## 10. 你现在要做的

### Step 1：查小程序注册时间

```
微信公众平台 → 设置 → 基本设置 → 账号信息
```

或者：
```
微信公众平台 → 设置 → 基本设置 → 微信小程序备案
（如果看到"立即备案"按钮 → 需要备案）
（如果显示"已备案" → 已完成）
```

### Step 2：根据注册时间决定

**如果是 2024-12-25 之前注册的**：
- ✅ 直接上传 + 提交审核（无需额外备案）
- 你可以直接发布

**如果是 2024-12-25 之后注册的**：
- 必须先在小程序备案入口提交备案材料
- 等 7-20 天审核通过
- 才能发布

### Step 3：域名备案 vs 小程序备案时间线

```
域名 ICP 备案:   [✅ 已完成] 2025-11-09 ~ 2027-09-16
小程序备案:    [待查]    2026-09-29 ~ 2026-10-19（如果需要）
2个月内有独立，不互相依赖
```

---

## 11. 一句话总结

- **域名备案** ≠ **小程序备案** ≠ **小程序认证**
- **三者独立**
- 域名备案：✅ 已完成（影响公网能否访问）
- 小程序备案：❓ 看你的注册时间（影响能否发布给真实用户）
- 小程序认证：❌ 不需要（个人开发不需要）
