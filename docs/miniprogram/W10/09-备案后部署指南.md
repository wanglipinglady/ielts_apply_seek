# 备案后部署指南（v3.9 / 2026-09-21）

> **场景**：阿里云域名备案审核通过后，把 Web 后端部署到公网（让小程序能真实访问）。
> **关键变化**：从「LAN IP」变成「公网域名 + HTTPS」。

---

## 1. 部署前清单

### 1.1 阿里云资源

- [ ] ECS 服务器（已购）
- [ ] MySQL（RDS 或自建，已配好）
- [ ] 域名（已备案）
- [ ] SSL 证书（**必须**，免费可申请）

### 1.2 代码准备

- [ ] uvicorn 跑得通（已验证）
- [ ] `.env` 中 `IELTS_BUDDY_WEB_DB_URL` 指向生产 MySQL
- [ ] `IELTS_BUDDY_ENV=prod`（强制走生产配置）
- [ ] `IELTS_BUDDY_JWT_SECRET` 强随机（不能 dev 默认）
- [ ] `IELTS_BUDDY_ADMIN_RESET_TOKEN` 强随机
- [ ] `IELTS_BUDDY_WECHAT_APPID` + `IELTS_BUDDY_WECHAT_SECRET` 填入

### 1.3 域名 / 证书

- [ ] 在阿里云控制台 → SSL 证书 → 申请免费证书（绑定 `ielts.example.com`）
- [ ] 证书审核通过后下载（Nginx 格式）
- [ ] 在小程序后台 → 开发管理 → 服务器域名，添加 `https://ielts.example.com`

## 2. 推荐架构

```
用户手机（微信）
   ↓ HTTPS
   ↓ (DNS: ielts.example.com → 阿里云 ECS 公网 IP)
   ↓
阿里云 ECS（公网 IP）
   ↓ Nginx (443, TLS 终止) + 反向代理
   ↓ HTTP (内网)
   ↓
uvicorn (127.0.0.1:8000) + FastAPI
   ↓
   ↓ SQLAlchemy + pymysql
   ↓
阿里云 RDS for MySQL (内网 3306)
   ↓
存储用户数据
```

**为什么用 Nginx？**
- ✅ HTTPS 证书卸载（uvicorn 不直接处理 TLS）
- ✅ 静态文件服务（未来可加）
- ✅ 负载均衡（多 worker）
- ✅ 简单的限流 / IP 黑白名单

## 4. systemd 配置（让 uvicorn 开机自启 / 崩溃重启）

### 4.1 service 文件

```bash
sudo vim /etc/systemd/system/ielts-web.service
```

```ini
[Unit]
Description=IELTS Buddy Web (FastAPI)
After=network.target mysql.service

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/opt/ielts_buddy
EnvironmentFile=/opt/ielts_buddy/.env
ExecStart=/usr/bin/python3.10 -m uvicorn ielts_buddy.web.main:app --host 127.0.0.1 --port 8000 --workers 4
Restart=always
RestartSec=5
StandardOutput=append:/var/log/ielts-buddy/web.log
StandardError=append:/var/log/ielts-buddy/web-error.log

[Install]
WantedBy=multi-user.target
```

```bash
sudo mkdir -p /var/log/ielts-buddy
sudo chown www-data:www-data /var/log/ielts-buddy

sudo systemctl daemon-reload
sudo systemctl enable ielts-web
sudo systemctl start ielts-web
sudo systemctl status ielts-web
```

### 4.2 查看日志

```bash
sudo journalctl -u ielts-web -f
# 或
sudo tail -f /var/log/ielts-buddy/web.log
```

## 5. Nginx 配置（TLS + 反向代理）

### 5.1 准备 SSL 证书

从阿里云 SSL 控制台下载 Nginx 格式的证书，得到两个文件：
- `ielts.example.com.pem`（证书）
- `ielts.example.com.key`（私钥）

```bash
sudo mkdir -p /etc/nginx/ssl
sudo cp ielts.example.com.pem /etc/nginx/ssl/
sudo cp ielts.example.com.key /etc/nginx/ssl/
sudo chmod 600 /etc/nginx/ssl/ielts.example.com.key
```

### 5.2 Nginx 配置

```bash
sudo vim /etc/nginx/conf.d/ielts.conf
```

```nginx
# 80 端口：HTTP 自动跳转到 HTTPS
server {
    listen 80;
    server_name ielts.example.com;
    return 301 https://$host$request_uri;
}

# 443 端口：HTTPS + 反向代理
server {
    listen 443 ssl;
    server_name ielts.example.com;

    ssl_certificate     /etc/nginx/ssl/ielts.example.com.pem;
    ssl_certificate_key /etc/nginx/ssl/ielts.example.com.key;
    ssl_protocols       TLSv1.2 TLSv1.3;
    ssl_ciphers         HIGH:!aNULL:!MD5;

    # 微信小程序要求的 HSTS
    add_header Strict-Transport-Security "max-age=31536000" always;
    add_header X-Content-Type-Options "nosniff" always;

    # 录音上传大小（30MB）
    client_max_body_size 30M;
    client_body_timeout 60s;

    # 日志
    access_log /var/log/nginx/ielts-access.log;
    error_log  /var/log/nginx/ielts-error.log;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 支持（未来用）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        proxy_read_timeout 60s;
    }

    # 健康检查（不记日志）
    location /healthz {
        proxy_pass http://127.0.0.1:8000/healthz;
        access_log off;
    }
}
```

### 5.3 测试 + 重启

```bash
sudo nginx -t        # 测试配置
sudo systemctl restart nginx
sudo systemctl status nginx
```

### 5.4 验证 HTTPS

```bash
# 从 ECS 本地测
curl https://ielts.example.com/healthz

# 从外部（你 Mac）测
curl -v https://ielts.example.com/healthz
```

| 域名类型 | 域名 |

## 8. 监控 + 备份

### 8.1 健康监控

```bash
# 加到 crontab（每 5 分钟检查一次）
*/5 * * * * curl -s https://ielts.example.com/healthz | python3 -c "import sys,json; d=json.load(sys.stdin); sys.exit(0 if d.get('mysql_reachable') else 1)" || echo "MySQL down!" | mail -s "IELTS Buddy Alert" you@example.com
```

### 8.2 数据库备份

```bash
# 每日备份（crontab）
0 3 * * * mysqldump -h <host> -u ielts_app -p<pwd> ietls_learn_online | gzip > /backup/ielts_$(date +\%Y\%m\%d).sql.gz
```

保留 7 天 / 30 天自动清理：

```bash
0 4 * * * find /backup -name "ielts_*.sql.gz" -mtime +30 -delete
```

```
/var/log/ielts-buddy/*.log {
    daily
    rotate 7

    missingok

    copytruncate
```

## 10. 故障应急

### 10.1 502 Bad Gateway

```bash
sudo systemctl status ielts-web     # uvicorn 没起？
sudo journalctl -u ielts-web --since "5 min ago"
# 常见：.env 配错 / 端口占用 / 依赖缺失
```

### 10.2 MySQL 连不上

```bash
# ECS 上
mysql -h <mysql_host> -u ielts_app -p ietls_learn_online
# 看错误

# 检查安全组（阿里云控制台）
# 看 3306 是否允许 ECS 内网 IP
```

### 10.3 小程序端报"不在以下 request 合法域名列表中"

```bash
# 检查小程序后台配置
# 域名必须是 https + 已备案 + 不带端口
# 修改后等 5-10 分钟生效（微信缓存）
```

### 10.4 502 + 504 + 内存爆

```bash
# 看 worker 数量
grep workers /etc/systemd/system/ielts-web.service

# CPU / 内存占用
top -p $(pgrep -f "uvicorn ielts_buddy")

# 调优：worker = CPU 核数 * 2
# 例：4 核 → 8 worker
```
