# 🔧 后端启动（必须）
```bash
cd /Users/wangliping/Public/selfProgram/ielts_apply_seek
export IELTS_BUDDY_LLM_API_KEY="sk-cp-<在此填入你的 MiniMax key>"
```

注意：用 `main:app`，不用 `app:app`（项目没 app.py）。**不要 --reload**。

# 🚨 避坑提示（必看）
1. **WXML 不支持三目 `? :` / `<text wx:for>` / `||` / `?.`** —— 用 JS 预计算字段
2. **录音按钮必须用 `<button bindtap="startRecord">`** —— 之前误绑 startPractice 是踩过的坑
3. **真机调试 mockCode 固定为 'dev_test_user001'** —— 否则每次登录都新建用户、错题本丢失
4. **后端 uvicorn 启动要 export LLM KEY** —— 配置文件读取时机是模块加载
5. **真机调试必须把 app.js 的 apiBaseUrl 改成 Mac LAN IP**（如 http://172.20.10.2:8000）
6. **pywhispercpp 模型从 hf-mirror.com 手动下载**（huggingface.co 被屏蔽）—— 放到 `~/Library/Application Support/pywhispercpp/models/`
7. **TRAE 沙盒 git 操作不稳定** —— 用 `launchctl asuser $UID bash -c 'git add ... && git commit ... && git push'`
8. **任何"重做某事"的 UI 入口（如重新录制）后端必须有 upsert** —— 不要假设 client 每次都生成新 key
9. **me/index 只保留"考试日历"** —— AI 写作批改/资料下载体验差，移到 Web
10. **录音参数：mp3 + 16kHz + 60s 上限** —— 与 Whisper 直接兼容

## 📝 使用方法

### 选哪个版本？

| 场景 | 推荐版本 |
|---|---|
| 新对话开启，要做新功能 | **A 标准版** |
| 接着上次对话继续做 | **B 极简版** |
| 修一个具体 bug | **C 调试专版** |

### 怎么用？

1. **复制对应版本**的整段文字
2. **粘贴到新对话第一句**
3. 把 `[在这里写具体任务]` 或 `[在这里描述 bug 现象]` 替换成你的实际任务
4. AI 读完文档后会先回答几个验证问题（标准版）→ 然后开始任务

### 关键好处

- AI 不用从零摸索项目架构
- AI 不用重复踩同样的坑（节省 30-60 分钟）
- AI 知道代码组织规范（WXML 限制、命名、API 命名）
- AI 知道真机调试的完整配置
- AI 知道 git 推送的可靠方式

## 📌 补充：3 个验证问题（标准版必读）

为了让 AI 真的读完文档，可以在 prompt 里加 3 个验证问题：

1. **小程序有几个 tab，分别是什么？**
   - 答：4 个 — 学习 / 复习 / 口语 / 我
2. **后端 ASGI 入口模块路径是什么？**
   - 答：`ielts_buddy.web.main:app`（不是 `app:app`，项目没 `app.py`）
3. **真机调试时 `apiBaseUrl` 应该填什么？**
   - 答：Mac 局域网 IP（如 `http://172.20.10.2:8000`），不是 `127.0.0.1`

**如果 AI 没答对，说明它没读文档或者快速跳过了，需要明确要求「请先读 W10/README.md」。**
