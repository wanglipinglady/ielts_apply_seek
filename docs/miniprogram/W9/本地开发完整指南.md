## 五、调试登录使用说明

小程序代码里 `app.globalData.debug = true`，所以**登录页会自动显示调试登录面板**：

1. 启动后端（步骤 1）
2. 打开微信开发者工具导入项目（步骤 3）
3. 进入登录页 → 展开"调试登录面板"
4. 输入任意字符串作为 openid（如 `test_user001`）
5. 点击"调试登录"
6. 成功进入学习 Tab

**调试登录原理**：
- 跳过 `wx.login()` 调用
- 直接调 `/api/wechat/dev-mock-login`
- 后端用 code 字符串作为 openid 创建/查询用户
- 返回真实可用的 access_token

## 六、真机调试流程

### 前置条件
- Mac 和手机连同一 WiFi
- 关闭 Mac 防火墙（或允许 8000 端口）

### 获取 Mac 局域网 IP

```bash
# macOS 查看 IP
ipconfig getifaddr en0
# 类似：192.168.1.100
```

### 修改小程序 API 地址

打开 `miniprogram/app.js`，修改 `apiBaseUrl`：
```js
apiBaseUrl: 'http://192.168.1.100:8000',  // 替换为你的 Mac IP
```

### 真机扫码

微信开发者工具 → 预览 → 扫码 → 手机微信里打开

## 七、常见问题

### Q1: 编译报错 `TypeScript compilation error`

**解决**：项目用 TS，确认 `miniprogram/pages/*/index.ts` 是 `.ts` 而非 `.js`。

### Q2: 登录提示"未配置微信接口"

**解决**：确保后端 `IELTS_BUDDY_WEB_DB_MODE=sqlite` 已设置，并使用了"调试登录"。

### Q3: API 请求返回 404

**检查**：
- 后端是否启动？→ `curl http://127.0.0.1:8000/api/wx/config-check`
- 小程序是否关闭了域名校验？→ 工具栏 → 详情 → 本地设置
- API 地址是否正确？→ `miniprogram/app.js` 的 `apiBaseUrl`

### Q4: 真机访问 127.0.0.1 失败

**原因**：手机访问的是自己的 127.0.0.1，不是 Mac 的。
**解决**：把 `apiBaseUrl` 改成 Mac 局域网 IP（如 `192.168.1.100:8000`）。

### Q5: 单词复习没有数据

**原因**：第一次使用没有复习记录。
**解决**：
- 先在"随机刷词"页面看几个词，触发错词入库
- 或后端手动灌入复习数据：
```bash
PYTHONPATH=src python -c "
from ielts_buddy.repositories.fallback_repo import create_fallback_container
c = create_fallback_container()
print(c.review_service.get_due_words(limit=5))
"
```
