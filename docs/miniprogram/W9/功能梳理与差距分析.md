## 二、微信小程序规划功能清单

### 2.1 设计原则

| 原则 | 说明 |
|------|------|
| **移动优先** | 短时长（1-10 分钟）、碎片化使用 |
| **场景化** | 通勤、排队、睡前等场景 |
| **数据共享** | 同一 MySQL，与 Web 端用户数据互通 |
| **功能裁剪** | 砍掉需要大屏/键盘的操作（如写作批改可简化为粘贴） |
| **离线优先** | 单词背诵支持离线缓存 |

### 3.2 缺口分析（按优先级）

#### 🔴 P0：阻塞主流程的问题

| 问题 | 位置 | 影响 | 修复方案 |
|------|------|------|---------|
| **浏览只有 5 条数据** | study/index | 用户感知功能不完整 | 后端响应 `words` 数组，前端已兼容，但 limit 需要 20+ |
| **测验无内容** | study/quiz | 新用户艾宾浩斯为空 | 后端预填一些"默认"学习记录 |
| **口语录音 UI 未实现** | speak/practice | Whisper 评分不能跑通 | 补录音按钮 + onStart/onStop |

#### 🟡 P1：核心功能缺失

| 功能 | 说明 | 工作量 |
|------|------|-------|
| **文章翻译** | LLM 翻译 + 生词提取 | ~300 行（wxml + js） |
| **写作批改 UI** | 用户粘贴作文 → 提交 → 展示 4 维分数 | ~250 行 |
| **考试日历** | 静态数据 + 倒数日 | ~150 行 |

#### 🟢 P2：增强体验

| 功能 | 说明 | 工作量 |
|------|------|-------|
| **工具集合** | 番茄钟 / 资料下载等快捷入口 | ~200 行 |
| **个人设置** | 通知、退出登录、绑定微信 | ~150 行 |
| **ClawBot 智能体** | 7×24 备考咨询 | ~400 行 |

|-----|--------|------|
| `/api/wx/study/vocab/list` | `{ words: [...] }` | 字段名是 `words` 不是 `items` |
| `/api/wx/study/vocab/random` | `{ words: [...], count: N }` | |
| `/api/wx/study/review/due` | `{ due_words: [...], count: N, today: 'YYYY-MM-DD' }` | 字段名 `due_words` |
| `/api/wx/study/mistakes` | `{ mistakes: [...] }` | 字段名 `mistakes` |
| `/api/wx/speak/practice/start` | `{ session_id, part, topic_id, topic, question, vocab, sample_answer, tips }` | |
| `/api/wx/grade/submit` | `{ overall_score, task_type, band_scores, error_summary, suggestions, annotations }` | |

> **前端已经做了兼容**（`words || items`、`mistakes || items` 等），所以字段差异不影响功能。
