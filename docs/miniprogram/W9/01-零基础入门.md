## 一、5 分钟搞懂微信小程序

### 1.1 什么是微信小程序

- **本质**：一个**跑在微信里的网页应用**（不是独立 App）
- **特点**：无需下载安装，扫码即用，占内存小
- **用户怎么用**：微信 → 搜索「屠鸭智取」→ 直接用
- **开发者怎么写**：用微信官方的「微信开发者工具」，写完后点「上传」→ 微信审核 → 审核通过 → 用户能搜到

### 1.2 小程序 vs Web 网页 vs 独立 App

| 维度 | Web 网页 | 微信小程序 | 独立 App |
|------|----------|------------|----------|
| 入口 | 浏览器 | 微信 | 应用商店 |
| 开发语言 | HTML/CSS/JS | WXML/WXSS/JS/TS | Java/Swift |
| 后端 | 任意 | 任意 | 任意 |
| 审核 | 无 | 微信审核 | 苹果/安卓审核 |
| 推送 | 邮件/短信 | 微信服务通知 | 系统推送 |

**关键点**：小程序的 UI 部分（`wxml` / `wxss`）是微信专属方言，但**业务逻辑（`js` / `ts`）就是标准 JavaScript**。

### 1.3 一句话总结架构

```
小程序（前端） ──HTTP──> 后端 FastAPI ──SQL──> MySQL
   ↑                                              ↑
   ↑                                              ↑
用户手机微信                                    阿里云 ECS
```

**你以后所有的学习，都围绕这 3 块：前端 / 后端 / 数据库**。

## 三、微信小程序基础概念（10 个必懂）

### 3.1 4 个文件 = 1 个页面

每个页面**必须**有 4 个文件（同名不同后缀）：

| 文件后缀 | 作用 | 类比 Web |
|----------|------|----------|
| `.ts` | 逻辑（数据 / 事件）| `script.js` |
| `.json` | 配置（标题 / 引入组件）| 无 |
| `.wxml` | 结构（标签）| `index.html` |
| `.wxss` | 样式（CSS 子集）| `style.css` |

**例子**：`pages/study/index/index.ts` + `index.json` + `index.wxml` + `index.wxss` = 1 个页面。

### 3.2 4 个核心 API

| API | 作用 | 类比 |
|-----|------|------|
| `wx.login()` | 拿微信临时 code | 浏览器 `navigator.geolocation` |
| `wx.request()` | 发 HTTP 请求 | `fetch` / `axios` |
| `wx.setStorageSync()` | 本地存数据 | `localStorage` |
| `wx.switchTab()` | 切换 Tab | `<a>` 跳转 |

### 3.3 数据绑定基础

```html
<!-- .wxml -->
<view>{{message}}</view>
<view wx:if="{{isLogin}}">已登录</view>
<view wx:for="{{items}}" wx:key="id">{{item.name}}</view>
<button bindtap="onTap">点我</button>
```

```ts
// .ts
Page({
  data: {
    message: '你好',
    isLogin: false,
    items: [{id: 1, name: 'apple'}, {id: 2, name: 'banana'}]
  },
  onTap() {
    this.setData({ message: '被点了' })
  }
})
```

**3 个核心指令**：
- `{{变量}}` = 插值
- `wx:if` = 条件渲染
- `wx:for` = 列表渲染（必须有 `wx:key`）

### 3.4 生命周期

每个 Page 自动有 4 个关键时刻：

```ts
Page({
  onLoad() { console.log('页面加载') },       // 首次加载
  onShow() { console.log('页面显示') },       // 每次显示
  onPullDownRefresh() { ... },                 // 下拉刷新
  onReachBottom() { ... },                    // 滚到底部
})
```

### 3.5 Tab Bar 配置

`app.json` 顶部声明 4 个 Tab：

```json
{
  "tabBar": {
    "list": [
      {"pagePath": "pages/study/index/index", "text": "学习"},
      {"pagePath": "pages/review/index/index", "text": "复习"}
    ]
  }
}
```

**限制**：Tab 页面只能用 `wx.switchTab` 跳转，**不能** `wx.navigateTo`。

### 3.6 网络请求（重要！）

小程序**必须**走 HTTPS，且**必须**配置「request 合法域名」。

```ts
// 正确
wx.request({
  url: 'https://api.your-domain.cn/api/wx/login',
  method: 'POST',
  header: { 'Content-Type': 'application/json' },
  data: { code: 'xxx' },
  success: (res) => console.log(res.data)
})
```

**注意**：开发期可以勾选「不校验合法域名」，但**生产必须配置**。

### 3.7 本地存储

```ts
wx.setStorageSync('token', 'xxx')           // 存
wx.getStorageSync('token')                  // 读
wx.removeStorageSync('token')               // 删

// 注意：单 key ≤ 1MB，整 storage ≤ 10MB
```

### 3.8 真机调试

1. 微信开发者工具 → 点「预览」→ 生成二维码
2. 微信扫码 → 真机调试
3. 控制台日志在工具的「Console」面板

### 3.9 上传 + 审核

1. 微信开发者工具 → 点「上传」→ 填版本号 → 提交
2. 登录微信公众平台 → 版本管理 → 找到刚才的版本 → 提交审核
3. 等待 1-7 天审核结果
4. 审核通过 → 手动点「发布」→ 全网可见

### 3.10 SKILL（v3.9 新概念）

- **本质**：把小程序能力"原子化"，让微信 AI 助手能调度
- **3 个文件**：
  - `SKILL.md`：人类可读的能力说明
  - `mcp.json`：机器可读的输入输出 schema
  - `index.js`：实际执行逻辑
- **好处**：用户可以在微信 AI 对话框说"给我抽 5 个词"，**不用打开小程序**

## 四、读懂「登录页」代码（手把手 10 分钟）

打开 `miniprogram/pages/auth/login/index.ts`：

```ts
const app = getApp() as any;        // ① 拿全局 app 实例

Page({                              // ② 注册一个页面
  data: {                          // ③ 页面数据
    nickname: '',
    loading: false,
    errorMsg: '',
  },

  onLoad() {                       // ④ 页面加载时自动调
    this.doLogin();
  },

  onNicknameInput(e: any) {        // ⑤ 输入框监听
    this.setData({ nickname: e.detail.value });
  },

  async doLogin() {                // ⑥ 核心登录逻辑
    this.setData({ loading: true, errorMsg: '' });

    // 6.1 调 wx.login() 拿临时 code
    const loginRes = await new Promise((resolve, reject) => {
      wx.login({ success: resolve, fail: reject });
    });
    const code = loginRes.code;   // 临时凭证，5 分钟有效

    // 6.2 调后端 /api/wx/login
    const res = await post<any>('/api/wx/login', { code });

    // 6.3 保存 token 到 storage
    app.saveToken(res.access_token);
    wx.setStorageSync('ib_refresh_token', res.refresh_token);
    app.globalData.user = res.user;

    // 6.4 跳到学习 Tab
    wx.switchTab({ url: '/pages/study/index/index' });
  },
});
```

**对照表**（小程序 ←→ Web）：

| 小程序 | Web 等价 |
|--------|----------|
| `Page({...})` | React `export default function Component() {...}` |
| `data: {...}` | React `useState({...})` |
| `this.setData({x: 1})` | React `setState({x: 1})` |
| `wx.login()` | 浏览器调用微信 API |
| `wx.switchTab` | React Router `navigate('/study')` |
| `wx.setStorageSync` | `localStorage.setItem` |

```html
<view class="container">

  <!-- 列表渲染（wx:for 必须有 wx:key）-->
  <view wx:for="{{words}}" wx:key="word" class="word-item card">
    <view class="word-main">
      <text class="word-text">{{item.word}}</text>
      <text class="word-phonetic">{{item.phonetic}}</text>
    </view>
    <text class="word-meaning">{{item.meaning}}</text>
    <text class="word-tag">{{item.pos}} · Band {{item.band}}</text>
  </view>
</view>
```

`index.ts` 关键部分：

```ts
Page({
  data: {
    words: [],          // 词库数据
    band: 7,            // 默认 Band 7
    activeTab: 'browse',
  },

  switchTab(e: any) {
    // 拿到 data-tab 属性
    this.setData({ activeTab: e.currentTarget.dataset.tab });
  },

  async loadVocabList() {
    const res = await get<VocabListResp>('/api/wx/study/vocab/list', {
      band: this.data.band,
      page: this.data.page,
      per_page: this.data.per_page,
    });
    this.setData({ words: res.words });
  },
});
```

**关键点**：
- `bindtap="switchTab"` = 点击触发 switchTab 方法
- `data-tab="browse"` = 自定义属性，方法里通过 `e.currentTarget.dataset.tab` 拿
- `wx:for` 必须有 `wx:key`（这里用 `word`，每个词的 word 字段唯一）

## 六、读懂后端「学习 API」代码

打开 `src/ielts_buddy/web/routers/wx_study.py`：

```python
from fastapi import APIRouter, Depends, HTTPException, Query
from ielts_buddy.services.review_service import ReviewService
from ielts_buddy.web.auth.deps import get_current_user

router = APIRouter(prefix="/api/wx/study", tags=["wx-study"])

# 关键：route + service 解耦
@router.get("/vocab/list")
async def wx_vocab_list(
    user: Annotated[WebUser, Depends(get_current_user)],  # ① 鉴权
    band: Optional[int] = Query(default=None, ge=5, le=9),  # ② 校验参数
    page: int = Query(default=1, ge=1),
    per_page: int = Query(default=20, ge=5, le=100),
) -> dict:  # ③ 返回 dict → FastAPI 自动转 JSON
    """词库浏览。"""
    vocab: VocabService = get_vocab_service()  # ④ 拿 service
    pool = vocab.filter_by_band(band) if band else vocab.all_words()
    if topic:
        pool = [w for w in pool if w.topic == topic]

    total = len(pool)
    start = (page - 1) * per_page
    items = pool[start:start + per_page]

    return {
        "words": [_word_to_dict(w) for w in items],
        "total": total,
        "page": page,
        "per_page": per_page,
        "total_pages": (total + per_page - 1) // per_page,
    }
```

**3 层架构**：

| 层 | 文件 | 职责 |
|-----|------|------|
| 路由 | `wx_study.py` | 接收 HTTP 请求 + 校验参数 + 调 service |
| 业务 | `review_service.py` | 真实业务逻辑（艾宾浩斯算法）|
| 数据 | `learning_repo` | 拼 SQL + 拿数据 |

**为什么这样分**：
- 改算法只动 service（不破坏 HTTP 契约）
- 改 HTTP 路径只动 route（不破坏业务逻辑）
- 改数据库只动 repo（不破坏上层）

## 八、调试技巧

| 问题 | 怎么排查 |
|------|----------|
| 页面空白 | 看 Console 报错；99% 是路径错或 JSON 解析错 |
| 网络 404 | 检查 `app.js` 的 `apiBaseUrl` 是否正确 |
| Token 401 | 跑 `wx.removeStorageSync('ib_access_token')` 重新登录 |
| 录音失败 | 检查 `permission` 字段，提示用户开启麦克风权限 |
| 真机白屏 | 看 Console + 确认 `request 合法域名`已配置 |
| 样式错乱 | 微信开发者工具 → 调试器 → 选真机调试模式 |

## 十二、卡住了怎么办

| 错误 | 解决方案 |
|------|----------|
| `Cannot find module` | `pip install -e .` 或 `pnpm install` |
| `AppID 不合法` | 公众平台 → 开发设置 → 复制正确的 AppID |
| `不在以下 request 合法域名列表` | 公众平台 → 开发管理 → 服务器域名 → 添加 |
| `用户拒绝授权` | 引导用户在小程序设置里开启 |
| `Token 已过期` | 调 `/api/auth/refresh` 刷新 |
| LLM 评分不准确 | 调 prompt 模板（在 `services/grading_service.py`）|
| Whisper 转写慢 | 改 GPU 模式或换小模型 |
