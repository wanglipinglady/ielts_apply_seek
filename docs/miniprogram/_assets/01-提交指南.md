### 2. 头像
| 字段 | 值 |
|------|---|
| 头像文件 | `avatar_logo.svg` → 转 PNG 后上传 |
| 推荐尺寸 | 144×144 px |
| 格式 | PNG / JPG，< 2MB，圆角 |

**SVG → PNG 转换命令**：
```bash
# macOS 安装 librsvg 后：
rsvg-convert -w 144 -h 144 avatar_logo.svg -o avatar_logo.png
# 或用 Python:
python3 -c "
import cairosvg
cairosvg.svg2png(url='avatar_logo.svg', output_width=144, output_height=144, write_to='avatar_logo.png')
"
# 或浏览器打开 SVG 后右键 → 另存为 PNG
```

## 审核预检建议

在正式提交审核前：
1. 先在微信公众平台「设置 → 基本信息」里把名称改为"屠鸭智取"，看是否命中保护词
2. 简介同步提交
3. 头像上传
4. 然后再上传代码 + 提审

## 提交材料使用流程

### 步骤 1：后台改名
- 路径：微信公众平台 → 设置 → 基本信息 → 小程序名称 → 修改
- 输入：**屠鸭智取**
- 每年 2 次免费改名机会（个人主体）

### 步骤 2：上传头像
- 转 PNG：参考上方命令
- 路径：设置 → 基本信息 → 头像 → 上传

### 步骤 3：填简介
- 复制 `00-小程序介绍文案.md` 第一节的 96 字简介

### 步骤 4：上传代码
- 用 miniprogram-ci 或微信开发者工具
- 命令：`./scripts/auto/01-upload_miniprogram.sh`

### 步骤 5：审核被驳回申诉（如有）
引用 `compliance_summary.svg` + `feature_matrix.svg` 作为补充材料说明：
- 9 项功能矩阵证明名称与功能对应
- 4 区合规自查证明无资质风险

## 命名决策记录

| 版本 | 名称 | 决定原因 |
|------|------|---------|
| v1 | 雅思搭子 | ❌ 微信审核未通过，需教育资质 |
| v2 | 英语干中学 | ⚠️ "干中学"是教育学术语，仍有培训嫌疑 |
| v3 | **屠鸭智取** | ✅ 4 字、押韵、AI 属性强、合规风险最低 |

最终选定 **屠鸭智取**：
- 「屠鸭」= 雅思考生圈内黑话（屠雅），无敏感词
- 「智取」= AI 智慧（智取生辰纲文化梗），含蓄表达 AI 属性
- 4 字好记、押韵、有文化感
- 不触发教育资质审核
