## 关键设计决策

1. **依赖隔离**：`[web]` extra 是可选的，CLI 安装 `pip install -e .` 不会装 FastAPI；只有 `pip install -e ".[web]"` 才装。这样 Web 开发不会污染 CLI 用户。
2. **HTMX vendored**：本机内网部署可能没外网；直接 vendored 到 `static/js/htmx.min.js`。
3. **包边界**：`ielts_buddy.web` 是新物理子包，CLI (`ielts_buddy.cli`) 不 import 它，反之亦然。
4. **配置集中**：`config.py` 只读环境变量，不直接读 config.toml（避免与 CLI 配置混淆）。
