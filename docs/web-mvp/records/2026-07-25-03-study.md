## 关键设计决策

1. **不走 ReviewService**：CLI 端 `ReviewService` 内部用 `SQLiteRepositoryContainer._conn`，FastAPI 同步端点跑在 threadpool 会爆跨线程错误。本阶段 study 路由直接用 `app.state.web_stats_conn`（`check_same_thread=False`）写 learning_records；艾宾浩斯 0-6 等级 + next_review 间隔复制自 `services/review_service.py`。

2. **页面路由用 `get_current_user_optional`**：与 pages.py 风格统一，未登录 302 → /login。API 路由 `/api/study/answer` 仍用 `get_current_user` 强制 401。

3. **HTMX 局部刷新**：`hx-post="/api/study/answer"` + `hx-target="#study-card"` + `hx-swap="outerHTML"`。服务端返回 partial `_study_card.html`，直接覆盖题卡区域。

4. **空队列提示根据 mode 区分**：复习空 → "今日复习已完成 🎉"；新词空 → "今日新词已学完 ✅ 休息一下，明天继续。"

5. **VocabService 单例复用**：`@lru_cache(maxsize=1)` 共享同一份词库索引，零修改。
