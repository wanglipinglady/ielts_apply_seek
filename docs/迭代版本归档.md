## 4. 完整版本表

### v0.1.0 — W1 + W2（基础层 + CLI 雏形）

| 项目 | 内容 |
|---|---|
| **发布** | 2026-06 中 |
| **目标** | 项目地基 + 第一个可用的 CLI 命令 |
| **关键能力** | 词库 / 学习记录 / 个人词库的基础 CRUD；6 个业务命令（vocab / stats / write / speak / listen / report） |
| **代码量** | ~ 3000 行（含 W1 基础工具） |
| **测试数** | 35 |
| **复盘** | `docs/W1_W2_阶段问题复盘.md` |
| **风险** | 早期阶段，所有功能都是"能用"但没考虑多用户、多 DB |

### v0.2.0 — W3（MySQL Repository 实现）

| 项目 | 内容 |
|---|---|
| **发布** | 2026-07 初 |
| **目标** | 让 online 模式（MySQL）落地，跟 local 模式（SQLite）双轨 |
| **关键能力** | 6 个 MySQL Repository；`create_repositories(mode)` 工厂；`RepositoryContainer` Protocol |
| **新增文件** | `repositories/mysql_repo.py`（~ 1430 行） |
| **代码量增量** | ~ 1500 行 |
| **测试数** | + 168 = 203（MySQL 6 个 Repository 测试） |
| **复盘** | `docs/W3_W6_阶段问题复盘.md` + `docs/W3_阶段详解与扩展指南.md` |
| **风险** | 缺 pyproject.toml 依赖（SQLAlchemy/PyMySQL/cryptography），开发机已装导致未发现 |

### v0.3.0 — W4（mode 分发落地）

| 项目 | 内容 |
|---|---|
| **发布** | 2026-07 初 |
| **目标** | 业务代码无感切换 SQLite / MySQL |
| **关键能力** | `get_mode()` 优先级解析（env > config > 默认 local）；`create_repositories()` 工厂模式 |
| **关键决策** | Protocol 鸭子类型而非 ABC 抽象类；容器注入式构造 |
| **测试数** | 203 → 215 |
| **复盘** | `docs/W3_W6_阶段问题复盘.md`（W4 章节） |

### v0.4.0 — W5（user_id 抽象）

| 项目 | 内容 |
|---|---|
| **发布** | 2026-07 初 |
| **目标** | 把"当前用户是谁"封装成可测试的函数 |
| **关键能力** | `get_user_id()` 抽象；env > config > 默认 1；为 W7 user_id 隔离铺路 |
| **关键决策** | **5 行函数救了 W7**——W5 时写死的"默认值 1"让 W7 不用改 30 处 |
| **测试数** | 215 → 240 |
| **复盘** | `docs/W3_W6_阶段问题复盘.md`（W5 章节） |

### v0.5.0 — W6（AuthService）

| 项目 | 内容 |
|---|---|
| **发布** | 2026-07 初 |
| **目标** | 多用户登录 / 登出 / 会话持久化 |
| **关键能力** | `AuthService.login / whoami / logout`；`session.json` 本地持久化；`user_repo.get_or_create` |
| **关键决策** | session 存 username + user_id（**无密码 / 无 token / 无 JWT**），跟方案 v2.0 第 1.2 节"无认证"边界一致 |

## 6. 已知债务（按风险排序）

### 6.1 高风险债务

| 债务 | 来源 | 影响 | 建议处理时间 |
|---|---|---|---|
| pyproject.toml 缺依赖（SQLAlchemy/PyMySQL/cryptography）| W3 | 干净环境 `pip install -e .` 后 online 模式跑不起来 | **W12.1 已修** |
| session.json 无 token / 无过期 / 跨 mode 共用 | W6 + W11 文档里讨论过 | 多用户共用电脑时用户 A 看到用户 B 数据；切 mode 必须重 login | 留 web 端阶段一起修（方案 v2.0 第 8 章） |
| 预存 ruff 46 个错误（deploy.py / feishu.py 等老文件）| W3 之前 | CI 不能 ruff 通过 | 专门技术债清理阶段 |

### 6.2 中风险债务

| 债务 | 来源 | 影响 | 建议处理时间 |
|---|---|---|---|

```powershell
# 1. clone
git clone <repo>
cd ielts_apply_seek

# 2. 创建虚拟环境（可选但推荐）
& 'D:\Program Files (x86)\Python3.13.3\python.exe' -m venv .venv
```
